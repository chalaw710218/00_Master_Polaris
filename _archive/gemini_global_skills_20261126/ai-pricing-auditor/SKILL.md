# 萬用 AI 供應鏈價格逆推與審計協議 (ai-pricing-auditor)

## Overview
這是一套專屬於「就醬點 / 寶桑物流」的數位商業間諜協議。當上游廠商給出報價時，本技能將利用全球大數據（期貨、海運費、關稅、匯率）模擬商業底層邏輯，強制剝離層層疊加的「摩擦成本」與「隱形溢價」，精準算出對方的底牌與毛利，並產出強而有力的談判話術。

## Dependencies
- 依賴內建工具 `search_web`，以抓取最新的原物料期貨、海運運費、匯率等即時總經數據。

## Quick Start
請使用者提供報價資訊，並輸入以下指令：
「請用 `ai-pricing-auditor` 幫我審計這個報價：智利冷凍鮭魚，中盤商報價每公斤 450 元，原箱未處理。」

## Workflow
Agent 在被呼叫此技能時，請向使用者取得以下資訊（若缺漏可自行推估或詢問）：
- **商品種類與產地**（如：澳洲牛肋條 / 台東高麗菜）
- **報價供應商層級**（如：進口大盤 / 區域中盤）
- **報價規格與狀態**（如：原箱 / 已修清分裝）
- **對方報價金額**

隨後，Agent 必須嚴格依序執行以下 4 個步驟，並產出審計報告：

### 1. 尋找「黃金錨定點」(Global Anchors)
使用 `search_web` 搜尋當前該商品對應的國際/國內指標：
- 原物料大盤價/期貨價（例如芝加哥牛肉、國際紙漿）。
- 運輸與能源成本（油價、海運費）。
- 近期特殊變數（天災、關稅制裁、匯率大跌等）。

### 2. 剝離「摩擦成本」並還原階層毛利 (Markup Deconstruction)
根據大數據常理推算，將供應鏈抽象為四層，逐步計算：
- **Level 1. 產地出貨價 (FOB/EXW)**：當地農漁民或原廠裸價。
- **摩擦成本**：跨國海運費、關稅、檢疫、冷凍倉儲與耗損率（如修清肉品需扣除 10-15% 失水/廢料）。
- **Level 2. 頂層大盤進貨價**：L1 + 摩擦成本 + 大盤合理毛利 (通常抓 12%~20%)。
- **Level 3. 中盤出貨價**：無加工轉手毛利約 10%~15%；含代工包裝約 20%~30%。

### 3. AI 心理戰預判 (Reverse-Engineering the Opponent's AI)
模擬對方進口商/盤商的 AI 系統（或商業操盤手）在當前局勢下，最可能給他的「出貨底線」是什麼？
例如：近期塞港導致運費上升，對方可能利用恐慌情緒「虛報溢價」；或者遇到庫存壓力，其實願意以「極速換現金」的底價出清。

### 4. 產出最終審計報告
請以 Markdown 格式輸出以下 4 點核心資訊：
1. **數據推估底牌**：明確寫出推估的「Level 1 產地價」與「Level 2 頂層大盤進貨價」落點區間。
2. **利潤與溢價分析**：扣除合理運費與耗損，直指對方在這次報價中大約賺取了多少毛利（% 與金額）？是否有不合理的溢價灌水？
3. **對手 AI 戰略預判**：揭露對方可能的定價策略與隱藏動機。
4. **談判話術支援**：給出一段 100 字以內的「高情商談判話術」，巧妙運用剛才推導出的數據底牌（如海運費、期貨價下跌等理由），溫和但堅定地戳破對方掩護，並提出我方要求的降價目標。

## Common Mistakes
- 忘記去搜尋即時的匯率或原料指數，導致推算與現實嚴重脫節。
- 未將「加工耗損率（如修清廢肉）」計入成本，導致誤判對方毛利過高。
- 談判話術過於強硬或無禮，破壞商業關係（必須是「高情商、有理有據」）。
