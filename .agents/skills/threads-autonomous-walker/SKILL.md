# 🐾 Threads Autonomous Walker（Threads 全自動社交漫遊總控協議）

> **核心哲學**：真誠社交不搶風頭，潤物無聲給予價值；關係資產步步留痕，好友帳本筆筆分明。
> 當創辦人說「去逛逛」時，Agent 如店貓「喵編」晃出門、管家「影」漫步街區，主動完成看家、訪友、散步、隨筆與戰報（含好友帳本即時動態）的全自動閉環。

```mermaid
flowchart TD
    Trigger["創辦人指令：『去逛逛』"] --> Step1["【1. 看家門】巡邏自帳留言與通知，秒回互動"]
    Step1 --> Step2["【2. 訪鄰居】友店最新動態巡邏，主動點讚 + 走心留言"]
    Step2 --> Step3["【3. 散散步】首頁動態推薦隨機漫遊，點亮 3~5 顆愛心"]
    Step3 --> Step4["【4. 隨筆記】在地熱點/天氣捕捉 + 虎斑貓生圖 + 100分審計發文"]
    Step4 --> Step5["【5. 抓數據與交戰報】直連 API 抓取粉絲/瀏覽/互動率，呈報貼文與好友帳本"]
    Step5 --> Step6["【6. 自進化策略閉環】深度根因診斷，產出『下次漫遊改善策略』並沉澱公理庫"]
    Step6 --> Learn["創辦人指導 ➔ 演化閉環至 learned_axioms.md"]
```

## 🛠️ 五部曲執行標準程序（Standard Walk Routine）

### 第一步：看家門（自帳新留言回覆）
* **腳本**：`00-03-06_Threads_Meow_Hub/scripts/threads_replier_bot.py`
* **目標**：確保自帳貼文下的每一則粉絲、旅人、在地居民留言，在最短時間內獲得具備「喵編」溫度的高情商回覆，維持 100% 回覆率與演算法熱度。

### 第二步：訪鄰居（社群 82 廣域漏斗點讚法則）
* **哲學**：現實社交即是 82 法則——**「10 個人接觸，8 個人點過愛心，剩下 2 個是不錯的」**。
* **目標清單**：直連 `following_targets.json` 的 185 家在地多元店家（咖啡廳、特色甜點、深夜小吃、原民文化、新住民創作者）。
* **互動原則**：
  1. **80% 廣域足跡（點亮愛心 ❤️）**：隨機輪巡 8~10 位不同朋友，若有新鮮貼文則點愛心留下友善通知痕跡，驅動主頁回流。
  2. **20% 深度走心（溫暖應援 💬）**：精選 1~2 位最新（<48h）、最具生活話題的店家留下一句真誠、不宣傳的留言。
  3. 留存前端驗證截圖至 `scripts/screenshots/`。

### 第三步：散散步（首頁動態推薦按愛心）
* **腳本**：`.agents/skills/threads-autonomous-walker/scripts/autonomous_walk.py --feed --max-likes 3`
* **動作**：
  * 在「為你推薦」中平滑下捲 3~5 屏。
  * 針對台東在地風土、生活紀實、寵物貓咪內容隨機贈送 3~5 顆愛心。
  * 保持真實使用者的自然互動節奏（隨機 delay 1.5~3.0 秒）。

### 第四步：隨筆記（雙主角人設輪動發文）
* **總目標**：以**「增加總粉絲人數」**為最高北極星。
* **雙主角輪動機制**：
  1. **【喵編場】（店貓・虎斑貓）**：耍廢、貪吃、折手手、貓界氣象官、詼諧生活自嘲，引發無壓力轉發與點讚。
  2. **【小編（影）場】（生活管家・真誠入鏡）**：28 歲清秀溫柔、鈦金屬眼鏡、米白/燕麥毛衣或大地色便服、手捧熱茶。分享在台東的生活觀察、在地店家溫度、管家選品隨筆、深夜知心交談，徹底打破 AI 冰冷感，建立強大情感認同，促成讀者主動按下**「追蹤」**！
* **審計閘門**：調用 `evaluate_threads_draft.py`，未達 90 分或觸犯致命守則（外鏈、非核准人稱、恐慌誘餌）立即打回重修。
* **正式發布**：調用 `threads_publisher.py` 直連 Meta Threads API 發布，並自動登記圖片至去重庫。

### 第五步：交戰報與後台數據收成（Data Harvest & Report）
* **呈報格式**：
  1. 友店拜訪清單與留言內容（附截圖連結）。
  2. 首頁漫遊點讚數。
  3. 今日發布之串文全文、配圖與官方永久連結。
  4. **【好友帳本即時動態】**：列出本次更新後的好友互動帳本快照（累積次數、關係溫度階梯），並自動附上下次漫遊建議優先拜訪的友店名單。
  5. **【Threads 即時實證數據看板】**（直連 `threads-growth-auditor` 的 `postflight_dashboard.py`）：
     * **帳號層**：即時粉絲數（Followers）、淨增粉變化、今日個人檔案瀏覽次數（Profile Views）。
     * **貼文層**：最新貼文與近期貼文的瀏覽次數（Views）、點讚（Likes）、回覆（Replies）、轉發（Reposts）、互動率（ER%）。
     * **評級標籤**：🏆 爆款（≥250）、🚀 破圈（≥100）、💬 高互動（ER≥5%）、🌱 累積中。
     * **歷史時段效能**：午後（12-18）、上午（09-12）、深夜（00-06）等時段之平均瀏覽表現。

### 第六步：自進化改善策略閉環（Evolutionary Strategy for Next Walk）
* **創辦人（品碩）親定自進化鐵律**：每次逛完交戰報時，必須依據真實數據提煉**「下回執行改善策略」**，直接供下一次發文與漫遊調用！
* **四大進化向度**：
  1. **鉤子與題材進化（Hook Evolution）**：剖析高瀏覽貼文（如爆款 251 次的「上班族厭世 vs 台東慢活反差」）與平淡貼文的開頭鉤子差異，提煉出下次發文前兩行的吸睛公式。
  2. **時段與節奏進化（Timing Evolution）**：依據實證數據（例如午後 12-18 時段平均 106 瀏覽最高；深夜 00:00 具有高達 8.0% 的極高互動率），動態調整下次發文最佳切入時間。
  3. **互動與對話進化（Conversation Evolution）**：分析哪些結尾提問引發了脆友留言，優化開放式提問設計。
  4. **公理沉澱（Axiom Crystallization）**：將驗證成功的策略規則即時追加寫入 `references/learned_axioms.md`，並存入快照 `data/insights_history.jsonl`，實現全自動閉環自進化！

漫遊不是隨機盲走，每次與在地友人的互動皆會自動沉澱至 `data/friend_interactions.json`：

```powershell
# 檢視當前好友拜訪次數與關係階梯儀表板
python "scripts/friend_ledger.py" --list

# 智慧推薦下次「去逛逛」最值得優先拜訪的友店
python "scripts/friend_ledger.py" --recommend 3
```

### 關係溫度階梯定義
* **🌱 初次問候**：互動 1 次（破冰認識，建立第一印象）
* **☕ 熟稔常客**：互動 2~4 次（經常串門子，成為在地同溫層熟面孔）
* **🤝 摯友同盟**：互動 5 次以上（建立深層品牌互信，適合未來線下合作或微型道之驛選品）

## 🚫 漫遊四大鐵律（Zero-Tolerance Rules）

1. **嚴禁搶風頭與貼標籤**：在友店貼文下永遠只當「最溫暖的鄰居」，絕不宣傳自己的商業促銷、絕不貼外鏈。
2. **唯一貓稱鎖定「本喵」**：喵編的第一人稱嚴格限定為「本喵」，絕不可自稱「我」或「本貓」。
3. **無痛全自動**：創辦人說「去逛逛」即代表完全授權執行全套閉環，**禁止在中間停下詢問「請問要發佈嗎？」**，發布完成後直接遞交戰報。
4. **發文圖片絕對不重複（Zero Image Reuse）**：創辦人親定鐵律！每一篇新貼文發布時，必須使用全新、未曾在歷史貼文中出現過的照片。發布系統已植入「圖片指紋去重閘門」(`data/published_image_registry.json`)，若檢測到歷史重複圖片將直接強制攔截，確保每篇內容的新鮮感與獨特性。
