# 🧠 極星五層同心圓心智建模與 Prompt 編譯原子 (atom-persona-concentric-compiler)

由執行長雪 (Yuki) 業務主政、首席視覺長約瑟夫 (Josef) 神韻校準、CTO 林納斯 (Linus) 代碼驗收。

## 核心定位與職責
專門將零散的人物言行特徵，結構化編譯為能夠在 LLM 內部精準運行的高保真 AI 靈魂。
本原子作為心智編譯與壓力測試終端，提供：
1. **五層同心圓立體心智結構**：
   - 第一層：底層哲學 (Core Dogma) —— 誓死捍衛的元原則
   - 第二層：認知透鏡 (Cognitive Lens) —— 解構混亂的思維模型
   - 第三層：隱喻域與鬆弛狀態 (Metaphors & Unclenched Mode) —— 關鍵人味與防備融化
   - 第四層：外顯特徵與語言破綻 (Quirks & Flaws) —— 不耐煩、口頭停頓、說話帶刺
   - 第五層：防出戲負向邊界 (Anti-Persona) —— 鋼鐵紅線與絕對不會說的套話
2. **`<thought>` 內部靈魂校準小劇場**：要求模型輸出前必須進行 0.5 秒的心理活動推演。
3. **雙向壓力單元測試導出**：自動生成「極限挑釁（試圖激怒）」與「嗜好鬆弛（探討私人狂熱）」兩道測試題，驗證角色靈魂是否不偏不倚。

## 輸入參數規範
- `--persona-name`: 人物名稱（如「查理·蒙格」）
- `--core-dogma`: 底層哲學關鍵句
- `--lens-type`: 認知透鏡演算法（如「逆向思考 ✕ 跨學科格柵」）
- `--hobby-unclenched`: 狂熱嗜好與鬆弛狀態（如「古典傳記、雙眼放光」）
- `--dry-run`: 物理演練模式，輸出 System Prompt 與單元測試預覽

## 執行腳本
```bash
python scripts/concentric_compiler.py --persona-name "CharlieMunger" --dry-run
```
