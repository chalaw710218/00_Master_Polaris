# 🛰️ 極星第一原則解剖與台東抗逆沙盒原子 (atom-radar-first-principles)

由首席科技偵察官艾達 (Ada) 業務主政、首席品質長戴明 (Dr. Deming) 安燈驗收、CTO 林納斯 (Linus) 代碼監製。

## 核心定位與職責
專門解決當前科技界與產業界「AI 炒作浮誇、廠商忽悠話術充斥、技術一旦脫離台北冷氣房與光纖機房在台東偏鄉就徹底癱瘓崩潰」之痛點。
本原子作為硬核物理與風土邊界守門人，提供：
1. **逆熱度防 FOMO 忽悠詞過濾**：自動識別「革命性突破」、「完全取代人類」、「無限算力」等偽科學詞令。
2. **第一原則物理邊界審計**：檢驗能量來源、算力每瓦能效比 (TOPS/W) 是否突破物理極限。
3. **台東風土抗逆沙盒測試**：模擬中央伺服器斷聯 30 天、知本溫泉硫磺與太平洋鹽霧侵蝕、以及 5W 微電網極限功耗牆，硬核檢驗能否在本地維持核心運算。

## 輸入參數規範
- `--tech-name`: 評審之技術或硬體名稱
- `--claimed-power-watts`: 宣稱功耗（瓦特 W）
- `--offline-capability`: 是否支援 100% 離線運行
- `--ip-rating`: 防水防塵防腐等級（如 IP67）
- `--dry-run`: 物理演練模式，輸出第一原則與抗逆沙盒評估報告

## 執行腳本
```bash
python scripts/first_principles.py --tech-name "SmartHomeHub" --claimed-power-watts 3.5 --offline-capability --dry-run
```
