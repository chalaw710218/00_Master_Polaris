# 📡 atom-trend-scout · 純粹熱點嗅探與常民情節深層轉譯器

> 🔒 **原子職責邊界 (Single Responsibility)**：只專注做一件事——**「把外部即時熱搜，深入轉譯為可供任何業務調用的常民情節 JSON」**。
> ❌ **絕不越界**：本原子不碰特定社群貼文格式、不發布 Meta API、不生成圖片，純粹輸出高純度情報切片。

---

## 🌊 創辦人親授「做深」三大硬核規格 (Depth Specifications)

### 1. 維度一【機理深度：常民心電圖穿透】
* 不只抓取熱搜關鍵字，而是深入計算該話題引發的**「大眾底層心理阻抗與情緒頻譜」**（焦慮、疲憊、物價壓力、渴望被理解？）。
* 深入提取「具體生活衝突情節」——讓閱讀者在 1.5 秒內產生無意識停留 (Dwell Time)。

### 2. 維度二【靈魂深度：三不三轉降維心法】
* **「三不」硬性物理過濾**：
  1. ❌ **不碰** 血腥獵奇與純天災悲劇消費；
  2. ❌ **不蹭** 黨派政治口水與對立仇恨；
  3. ❌ **不跟** 未經證實的虛假八卦。
* **「三轉」降維溫暖轉譯**：
  1. ⭕ **轉為打工人心電圖**：將大盤指數、科技新詞轉化為下班後的一杯溫熱紅酒或宵夜慰藉；
  2. ⭕ **轉為常民柴米油鹽**：將通膨與經濟波動轉化為產地直送的新鮮蔬菜與誠信價格底氣；
  3. ⭕ **轉為孝親居安守護**：將社會孤獨與老齡化轉化為替遊子問候長輩的到府溫暖。

### 3. 維度三【抗逆深度：林納斯極限韌性】
* 具備網絡超時指數退避重試（Jitter Backoff）。
* 斷網或 API 異常時，毫秒級自動優雅降級回退至**「本地常民長效情節快照庫」**，保證 `Exit Code == 0`，永不阻塞上游調用管線！
