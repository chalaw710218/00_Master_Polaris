# 👑 極星紅珠大赦免與漏斗停止折騰原子 (atom-deming-redbead-funnel)

由首席品質長戴明博士 (Dr. Deming) 業務主政、CTO 林納斯 (Linus) 架構監製、執行長雪 (Yuki) 營運協同。

## 核心定位與職責
專門解決團隊在業務推進時「大家明明很努力、甚至天天熬夜加班，但錯誤依然頻發，導致彼此自責、士氣低落、長官好心頻繁改動規則反而讓系統徹底混亂崩潰」之組織劇痛。
本原子作為系統診斷與心理驅逐恐懼終端，提供：
1. **虛擬紅珠實驗 (Red Bead Reality Check)**：將失誤場景抽象為「珠盒（外部環境）」與「木勺（現行工具流程）」，精算固有缺陷率，證明 94% 錯誤完全由系統決定。
2. **頒發《戴明系統大赦免狀》**：正式宣告第一線同仁 100% 免責，徹底破除盲目自責與考核恐懼，恢復心理安全感。
3. **戴明漏斗手術刀 (Funnel Anti-Tampering)**：識別並切除「好心微調（如臨時晨會、雙重重工審批、頻繁改動排班）」等放大混亂之無效動作，下達《立刻停止干預令》。

## 輸入參數規範
- `--issue-domain`: 發生卡關或失誤之領域（如「外送訂單延誤」、「社群文案互動低迷」、「代碼型別報錯」）
- `--current-tampering`: 目前團隊採取的應對微調措施
- `--dry-run`: 物理演練模式，輸出紅珠統計歸因、大赦免狀與停止干預令

## 執行腳本
```bash
python scripts/redbead_funnel.py --issue-domain "外送派單偶發延誤" --current-tampering "天天開晨會檢討且手動改派單" --dry-run
```
