# 🦅 極星司法裁判全文與票據信用穿透原子 (atom-forensic-judicial-audit)

由首席黑色調查官渡鴉 (Raven) 業務主政、首席法務顧問雪柔 (Falcon) 法律協同、CTO 林納斯 (Linus) 代碼驗收。

## 核心定位與職責
專門解決商業合作或借貸中「表面開豪車住豪宅、實則背負數千萬司促字支付命令與高利貸本票」之債務地雷，以及政商幕後黑手讓小弟工頭出面頂罪（單純查被告查不到前科）之欺瞞痛點。
本原子作為司法信用穿透終端，提供：
1. **司法票據與強制執行穿透**：鎖定關鍵案由（司票字本票裁定、司促字支付命令、給付票款），精算債務總額與未清償本息。
2. **裁判書「案外人與證人」全文反向穿透**：以目標姓名、公司名或車牌為關鍵字檢索判決內文筆錄，揭露幕後主謀指示頂罪證據。
3. **債務風險評級**：輸出無盲區之司法信用評級（綠燈正常 / 黃燈民事爭議 / 紅燈重大違約 / 黑色高危老賴）。

## 輸入參數規範
- `--target-entity`: 目標個人姓名或企業統編
- `--target-id-no`: 統一編號或身分證字號（用於精確比對）
- `--deep-witness-scan`: 是否開啟案外人與證人全文檢索（預設開啟）
- `--dry-run`: 物理演練模式，輸出司法票據穿透報告

## 執行腳本
```bash
python scripts/judicial_audit.py --target-entity "SampleTargetCorp" --dry-run
```
