# 👵🏡 生活管家孝親安居工單排程與 5D 定價底座原子技能 (Care Order Dispatcher Atom)

> **所屬技能組**：生活管家 / 業務排程底座  
> **核心職責**：專精於「五大孝親服務模組工單生成、5D 透明價格試算、車資與代墊解耦、現場防呆工具箱裝備檢核、寶桑 3PL 派工排程」。  
> **原技能母體**：`lifebutler-care-artisan`

---

## 核心功能與深度特性
1. **五大孝親旗艦服務標準模組 (5 Care Modules)**：
   - `escort`：長輩就醫陪診（2小時 NT$ 1,200，超時 400/h，醫囑速記＋平安返家）。
   - `anti_slip`：居安無憂（浴室防滑奈米塗層 ＋ 一字扶手安裝 ＋ 配電盤紅外熱像巡檢，NT$ 2,999）。
   - `grooming`：體面長青（臥床長者醫療級靜音集塵理髮修容，NT$ 600）。
   - `biography`：傳家之寶（高齡長者口述歷史訪談印製硬殼回憶錄，NT$ 6,800）。
   - `soft_meal`：暖胃風土（每週常溫高壓軟袋刺蔥燉湯 ＋ 低 GI 養生膳，NT$ 750/週）。
2. **標準工單序號與物理防呆檢核**：
   - 自動生成工單號碼（如 `CARE-20261113-01`），明定委託兒女、長輩姓名、到府家宅地址與特殊備註。
   - 內建戴明工具箱防呆：穿戴鞋套、靜音集塵電剪、FLIR 熱像儀、長輩溫開水保溫壺。
3. **5D 明碼定價與代墊款解耦**：
   - 勞務服務費透明固定，計程車資與代買藥品費用憑發票「實報實銷」，絕不混算。
4. **乾跑防呆 (Dry-Run Support)**：
   - 支援 `--dry-run` 模擬工單試算與排程，輸出標準 JSON 與工單 Markdown。
