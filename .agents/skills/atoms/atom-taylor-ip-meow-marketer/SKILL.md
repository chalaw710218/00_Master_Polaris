## 核心設計哲學：喵編角色行銷三大鐵律

商業行銷最忌生硬冷酷，喵編是軟化商業心智摩擦最強的人格化引力：

1. **唯一合法自稱「本喵」 (Sole Feline Pronoun)**：
   * 絕不使用「小編」、「本貓」、「我」或冷血客服代號。
2. **真貓行為生態學與零恐怖谷 (Zero-Uncanny Ethology)**：
   * 動作必須符合貓科解剖學：揣爪母雞蹲、下巴搭在木盒、踩奶、鼻尖輕嗅、尾巴隨磨豆機聲微晃。
   * 嚴禁人類怪異手勢擺拍、嚴禁咖啡桌上放生魚等破壞場景可供性之假圖。
3. **貓叫真實律與字幕翻譯 (Real Feline Vocalization)**：
   * 貓咪絕不開口說人話！喵叫純真（`喵嗚～`、`呼嚕嚕...`），所有人類語言強制標註為「（字幕翻譯：...）」。
4. **傲嬌吃貨幽默接梗**：
   * 絕不低頭求購買，以傲嬌視角監督人類備餐，用「魚肉很鮮本喵准許你們吃」的幽默化解促銷反感。

## 執行腳本與參數

專屬腳本位於 `scripts/taylor_ip_meow_marketer.py`。

### 命令行介面 (CLI)

```bash
python scripts/taylor_ip_meow_marketer.py --topic "冬季低溫老薑旗魚骨原湯上架" --dry-run
python scripts/taylor_ip_meow_marketer.py --verify-text "小編今天為大家帶來好吃的魚魚..."
```

### 核心參數
- `--topic`：行銷貼文主題或商品名稱。
- `--verify-text`：待檢驗之喵編草案，審查是否觸犯人設禁忌（如自稱小編、貓說人話）。
- `--dry-run`：預演模式。
