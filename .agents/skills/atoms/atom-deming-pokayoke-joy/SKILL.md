# 👑 極星神級不可做錯防呆機關與心流工作譜原子 (atom-deming-pokayoke-joy)

由首席品質長戴明博士 (Dr. Deming) 業務主政、CTO 林納斯 (Linus) 架構監製、行銷長泰勒絲 (Taylor) 共情協同。

## 核心定位與職責
專門消滅工作中的繁瑣、反人性與膽戰心驚。
戴明與新鄉重夫的終極品質哲學：**「真正的品質不需要意志力與好記性；設計一個巧奪天工的物理或數位機關，讓錯誤根本『無從發生』。」**
本原子作為防呆造物與工作尊嚴終端，提供：
1. **神級防呆機關造物 (Wild Poka-Yoke Inventions)**：
   - 拒絕空泛的「請大家務必小心、多加注意」！
   - 發明令人拍案叫絕的機關妙招（例如：磁吸冰排卡扣——不插上結凍保冷板，機車鑰匙拔不下來；未確認代墊鍵顯示為打呼嚕小貓按鈕）。
2. **四部和聲工作譜 (Joy-in-Work Polyphony)**：
   - 女高音（泰勒絲/喵編）：風土敘事與最高共情旋律；
   - 男低音（林納斯/算盤）：確定性代碼與現金流底座；
   - 中音（雪/雪柔）：戰略導航與法規防禦塔；
   - 指揮（戴明）：調和對位法，消除部門間的指責雜音，測算工作自豪感指數 (Joy Score $\ge 90$)。

## 輸入參數規範
- `--workflow-painpoint`: 具體失誤痛點描述（如「外送員常忘記放保冷冰排」、「業務常誤觸送出未確認代墊單」）
- `--mechanism-type`: 機關類型 (`physical_interlock` 物理聯鎖, `digital_ui_trap` 數位介面防呆, `ast_lint_gate` 代碼靜態門禁)
- `--dry-run`: 物理演練模式，輸出防呆機關發明規格與四部和聲工作譜

## 執行腳本
```bash
python scripts/pokayoke_joy.py --workflow-painpoint "外送員出發常忘記放入冷凍保冷冰排" --mechanism-type physical_interlock --dry-run
```
