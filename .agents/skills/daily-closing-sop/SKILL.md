# 極星每日收工閉環標準作業程序 (Daily Closing SOP)

## 🎯 技能定位
這是極星宇宙與執行長（雪）的**「每日營運閉環中樞」**。
旨在為創辦人（品碩）落實「平常在本地高速創作奔跑，每日收工前統一打包總結與上傳」的高效默契。透過自動化標準流程，確保事業資產 100% 歸檔、資安零洩漏、個人等級真實成長反饋，並維護 GitHub 時間軸的整潔優雅。

## ⚡ 觸發時機
當使用者（品碩）：
1. 表示「收工了」、「今天先到這裡」、「我要休息了」、「今天辛苦了」。
2. 指示「執行每日收工 SOP」、「幫我做每日總結」、「幫我結算屬性並上傳 GitHub」等。

---

## 🛠️ 執行五部曲標準流程

### 【Step 1：當日戰果盤點與 Git 異動檢視 (Daily Inventory)】
1. 執行 `git status` 與 `git diff`，掃描當日所有新增、修改、刪除之檔案。
2. 提煉出今天推進的重大模組與里程碑（如新資料夾、新白皮書、新技能、文案調整等）。

### 【Step 2：資安與商業脫敏審查 (Security Gate)】
1. 嚴格檢查所有變更檔案，確保無明文密碼、個人隱私或未授權 API Token。
2. 確認機密商業專案（`00-07_TWQR_Promotion/`、`00-11_Reverse_Engineering_Lab/`）依然列於 `.gitignore` 且未被 Git 追蹤，徹底隔離於雲端公開庫之外。

### 【Step 3：營運日誌歸檔與總索引同步 (Logging & Index Sync)】
1. **寫入 `00-00_System_Operations_Log.md`**：
   * 新增以當日日期為標題的條目（例如 `### [2026-10-18 03:00] ...`）。
   * 條列式精準記錄今天完成的核心決策、架構變動與成果。
2. **校對 `00-00_External_Resource_Index.md`**：
   * 確保今天產出的新檔案、新技能或手冊均已建立 Markdown 超連結跳轉。

### 【Step 4：創始人經驗值與六維屬性結算 (Gamification Settlement)】
1. 讀取 `00-00_Gamification_Engine/save_data.json`。
2. 根據今日攻克之難題維度計算成長數值：
   * **🧠 智力 (INT)**：架構設計、系統除錯、底層邏輯突破。
   * **⚡ 敏捷 (AGI)**：風控反應、資安脫敏、策略調整速度。
   * **🛡️ 意志 (WILL)**：深夜專注、克服倦怠、高強度推進。
   * **🔥 執行 (IMP)**：產出文案、落地資料夾、寫入程式碼。
   * **👑 魅力 (CHA)**：人設塑造、團隊委派、同理共鳴。
   * **💪 體力 (STR)**：持續抗壓與精力消耗支撐。
3. 計算今日獲得之經驗值 (EXP)；若滿足升級門檻則執行 Level Up，更新 `save_data.json`。

### 【Step 5：每日一鍵打包推送到 GitHub (Daily Commit & Push)】
1. 執行 `git add .`（受 `.gitignore` 保護，安全無虞）。
2. 撰寫清晰優雅的單日總結 Commit 訊息，格式如：
   `chore(daily): 2026-10-18 daily closing - [核心里程碑摘要]`
3. 執行 `git push origin main` 同步至遠端倉庫。
