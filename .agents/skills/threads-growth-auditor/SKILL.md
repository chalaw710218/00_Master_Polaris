# 📈 Threads Growth Auditor（Threads 數據審計與成長指南針）

> **核心信條**：左手有溫度的在地故事，右手冷靜客觀的後台數據。
> 沒有數據檢驗的自信只是自我感覺良好；只看數據則會滑向標題黨與誘餌互動。兩者缺一不可。

## 什麼時候使用

| 創辦人/情境 | 執行 |
| :--- | :--- |
| 「這篇草稿及不及格？」／任何貼文發布前 | 第一軌 `preflight_audit.py` |
| 「最近戰果如何？」／「去逛逛」收尾回報 | 第二軌 `postflight_dashboard.py` |
| 覆盤、決定下一篇主題與發文時段 | 第三軌（見下） |

## 第一軌：發布前質量閘門

```powershell
python ".agents/skills/threads-growth-auditor/scripts/preflight_audit.py" --file draft.txt --persona meow
```

五維度各 20 分：鉤子張力、短句呼吸感、零外鏈無硬廣、人設完整、結尾開放式提問。
**門檻 90 分**（`--threshold` 可調）。退出碼 0 通過、1 打回。

**致命守則（觸犯即打回，與分數無關）**
1. 內文含外部連結。
2. 含急迫/誘餌字眼：`留言+1`、`快來買`、`限時`、`搶購` 等。
3. 喵編貼文誤用「本貓」（唯一許可人稱：**本喵**）。
4. 超過 500 字。

> ⚠️ 此審計是**規則型代理指標**，只能擋下已知的低級錯誤，**不能保證貼文會有成效**。分數 100 ≠ 會爆；實際成效以第二軌數據為準。

## 第二軌：發布後客觀實證儀表板

```powershell
python ".agents/skills/threads-growth-auditor/scripts/postflight_dashboard.py" --limit 15
```

- 自動探索最近貼文（不需手動維護 ID 清單）。
- 指標：瀏覽、按讚、留言、轉發、引用、**互動率 = (讚+留言+轉發+引用)/瀏覽**。
- 評級：🏆 爆款（瀏覽≥250）／🚀 破圈（≥100）／💬 高互動（互動率≥5%）／🌱 累積中。
- 每次執行追加快照到 `data/insights_history.jsonl`，可追蹤同一篇貼文隨時間的成長。
- 帳號層：追蹤者數、個人檔案瀏覽。

## 第三軌：根因診斷與策略沉澱（由 Agent 依數據執行）

1. 比較「高成效 vs 低成效」貼文的**主題、發布時段、是否連動友店、是否有圖**。
2. 只有在**同類樣本 ≥ 3 篇且貼文已滿 24 小時**時，才把觀察升級為策略；否則標註為「假說」。
3. 將確認的結論寫入 `references/learned_axioms.md`，並以 `shadow-soul-memory` 記錄重大里程碑。

## 判讀紀律（避免誤讀數據）

- **樣本數很小**：帳號追蹤者個位數～兩位數時，單篇數據雜訊極大，勿以一兩篇下定論。
- **未滿 24 小時的貼文**數據尚未成熟，儀表板會標示 ⏳，不納入時段統計。
- **相關不等於因果**：例如深夜貼文瀏覽較低，可能是時段，也可能是題材；需更多對照樣本。
- **留言數可能含我們自己的回覆**：API 的 `replies` 疑似包含官方帳號自己的回覆，會讓互動率偏高；評估真實互動時，需人工扣除自己的回覆。
- **瀏覽 ≠ 生意**：最終看追蹤成長、主頁瀏覽與實際詢問／訂單，不要只優化瀏覽數。
- 嚴禁為了拉高數字而使用誘餌互動（`留言+1` 等）；這會犧牲長期信任。

│   ├── _common.py              # 金鑰載入（向上尋找 .secrets.env）
