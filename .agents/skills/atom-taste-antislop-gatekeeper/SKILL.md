# 🎨 約瑟夫✕尼奧·反AI塑料套版與一屏一區視覺門禁原子 (Anti-Slop Taste Gatekeeper Protocol v1.0)

> **核心職責**：徹底驅逐「AI 塑料感 (AI Slop)」與廉價模板！守護極星前端 UI 的視覺尊嚴與克制美學，以冷酷的物理代碼檢驗每一個區塊的高度、留白與對齊秩序。

---

## 一、 反 AI 塑料感八大死線門禁

1. **一屏一區塊律 (One Section Per Screen)**：
   * 首屏僅留給 Hero 大標與核心價值，高度嚴格鎖定於 100vh（或 1440x900 基準），嚴禁第二區塊標題在首屏突兀探頭。
2. **禁止浮誇假 3D 與無效卡片堆疊**：
   * 嚴禁隨意堆砌意義不明的 3D 浮誇插圖、發光漸層泡泡或裝飾性卡片。
   * 以「真實產品截圖、真實常民生活攝影、純粹漢字排版」為主角。
3. **左右等邊對齊 (Equal Content Edges)**：
   * 12 欄網格嚴守左右邊距完全對稱，禁止邊緣微小位移與肉眼可見的視覺抖動。
4. **克制微互動 (Quiet Micro-Interactions)**：
   * 懸停提升僅限 2px，圖片微放大 1.02~1.03x，杜絕大角度 3D 傾斜 (Tilt) 與廉價跑馬燈。

---

## 二、 執行工具規範

* 執行腳本：`scripts/antislop_gatekeeper.py`
* 支援指令：
  ```bash
  python scripts/antislop_gatekeeper.py --audit-html --file-path "index.html"
  python scripts/antislop_gatekeeper.py --sample-audit
  ```
