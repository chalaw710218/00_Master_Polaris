## 📜 詳細開發與實測日誌 (Changelog & Audit Trail)

### 📅 [2026-10-29] 模組 M5 突破：RESTful API 簽發與極速下單測試成功
* **背景診斷**：
  * 原生網頁前台因包含大量歐美式外帶流程（選分店、選自取時段、填寫繁瑣個資）與 Blade 動態視圖渲染，在 GCP 免費層伺服器反應偏慢，且不利於店面現場員工在櫃檯 3 秒內下單。
  * 經系統路由檢驗，發現 TastyIgniter 原生具備完整的 RESTful API（`GET /api/menus`, `POST /api/orders`, `PATCH /api/orders/{id}/status`）。
* **實測步驟與成果**：
  1. 使用 Artisan 指令為管理員成功簽發專屬 API Token：`polaris-pos-token`。
  2. 呼叫 `GET /api/menus` 成功以 JSON 格式取得全店 13 道菜單品項（包含第 13 號「都蘭刺蔥牛肉麵」定價 180 TWD）。
  3. 模擬櫃檯 POS / 行動端，直接向 `POST /api/orders` 發送點餐請求。
  4. **實測成果**：伺服器於 **1.6 秒內** 回傳 `201 Created`，資料庫正式生成 **第 7 號訂單（林納斯 CTO / 0912345678 / 自取 / 狀態 Received）**，後台即時同步顯示！
* **工程意義**：
  * 徹底將「後端訂單核反應爐」與「前端介面」解耦。未來可自由對接超輕量秒開網頁、LINE 官方帳號點餐、或哈爸的微型硬體收銀按鈕。
