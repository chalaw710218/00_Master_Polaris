## ⚡ 內閣協同作戰動線

1. **原始素材存證 (`00_Raw_Source/`)**：
   * 將夥伴的原始貼文文字存入 `partner_original_post.md`。
   * 將原始圖片/截圖放入此目錄，保留最純淨的第一手資料。
2. **生活管家在地語境轉譯 (`01_Marketing_Copy/`)**：
   * 破除生硬技術說教，由泰勒絲結合「生活管家」常民視角，撰寫高轉化率的推廣文案矩陣（包含喵編活潑親切版、闆仔實戰商人版、生活管家專業推薦版）。
3. **高保真資訊圖卡設計 (`02_Visual_Assets/`)**：
   * 由約瑟夫將課程核心亮點（適合誰、能學到什麼、時間地點）轉化為手機滑過 1.5 秒即能看懂的資訊圖卡。
4. **創辦人一鍵審批與自動發布**：
   * 經品碩確認後，直接調用 `facebook-publisher` 與 `threads-publisher` 執行排程發布。
