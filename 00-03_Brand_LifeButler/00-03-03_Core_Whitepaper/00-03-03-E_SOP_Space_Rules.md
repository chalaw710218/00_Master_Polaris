# 附件 E：家宅公共區域營運守則與空間使用規範

本附件旨在規範「家宅 Community Hub」之公共場域維護、冷鏈設備管理、排班值勤紀律與環境整潔標準，落實共好精神，維持乾淨、整齊、安全之社區共享空間。

---

## 一、 核心場域定位與邊界原則

1. **共享與共好原則**：
   * 本場域為「與合作夥伴共用之協同空間」，生活管家團隊與志工夥伴應時刻秉持**「自律、整潔、尊重」**之基本態度，嚴格遵循公共區域維護守則，先求不干擾、次求加值共好，現階段暫不另立繁複細部規範。
2. **資產邊界釐清**：
   * **家宅內部冷鏈設備**：臥式 6 呎上掀式冷凍櫃、直立式展示冷藏櫃為家宅現場運作之核心硬體，專供生鮮分裝暫存、便當快閃冷藏與社區「冰箱借冰」服務使用。
   * **外租大冷凍庫聲明**：外租大冷凍庫之費用與權責**全權隸屬於「寶桑物流」**，屬於大宗批發供應鏈後勤體系，不在本家宅空間規範與管轄範疇之內。

---

## 二、 空間功能劃分與暫存規範

現階段採極致精益之場域利用，公共空間嚴禁堆置凌亂雜物：

```
                      ┌───────────────────────────────────────┐
                      │          家宅公共場域 (共用空間)         │
                      │                                       │
                      │  ┌─────────────────┐ ┌─────────────┐ │
                      │  │  志工值勤服務台 │ │ 社區取貨區  │ │
                      │  │  • 系統登錄     │ │ • 秩序核單  │ │
                      │  │  • 時間銀行記錄 │ │ • 走動自取  │ │
                      │  └─────────────────┘ └─────────────┘ │
                      │                                       │
                      │  ┌─────────────────────────────────┐ │
                      │  │   【唯一倉儲暫存區】(冷鏈設備)    │ │
                      │  │   • 臥式 6 呎冷凍櫃 (低溫暫存)    │ │
                      │  │   • 直立式冷藏櫃 (借冰/便當/鮮奶) │ │
                      │  └─────────────────────────────────┘ │
                      └───────────────────────────────────────┘
```

1. **倉儲暫存嚴格限制**：
   * **暫存區僅限於「冷凍冰箱」與「冷藏冰箱」內部**。
   * 嚴禁在公共走道、地面或桌面任意堆放乾貨紙箱與私人物品，確保共用場域之動線流暢與視線通透。
2. **冷鏈設備收納紀律**：
   * **分區擺放**：冷藏與冷凍櫃內需落實「主要商品/分裝肉品」、「好市多代購品」、「借冰品（需貼標）」之分層分籃管理。
   * **定期除霜與清潔**：每週六值班結束前，需檢視冰箱內部衛生，落實除霜與層架擦拭，杜絕異味與血水殘留。

---

## 三、 志工排班時段與現場紀律

1. **法定排班值勤時段**：
   * **值勤時間**：每週 **週四、週五、週六 15:00 ～ 18:00**（每班 3 小時）。
   * **出勤登錄**：值班人員抵達與離開時，需於專屬 LINE 系統完成簽到退，作為核算「時間銀行數位點數」或「微型津貼」之唯一憑證。
2. **值勤核心任務**：
   * 接待前來自取生鮮、便當或領件之社區鄰里。
   * 協助檢查借冰物品標籤（姓名、電話、存入日期），落實「當天免費、次日起 20 元/天」之登錄。
   * 維護現場秩序，避免人流聚集喧嘩影響共用場域之其他夥伴。

---

## 四、 公共區域「乾淨與整齊」維護守則 (清潔防線)

所有使用家宅公共空間之人員（包含創辦人、志工、外勤車手與取貨住戶），均須無條件落實以下守則：

1. **物歸原位、桌面淨空**：
   * 凡使用過之剪刀、膠帶、標籤機、電子秤或文具，使用完畢**立即歸位**。
   * 服務台與公共桌面需隨時維持淨空，不留未喝完之飲料杯與個人垃圾。
2. **垃圾即時分類清運**：
   * 現場拆卸之紙箱、封箱膠帶與真空包裝袋邊料，需即時壓平分類投入指定回收箱，不得落地或堆置於門口。
3. **離場「一分鐘巡檢」機制**：
   * 每日值班時段結束（18:00）或工作人員最後離開場域前，執行 60 秒巡檢：
     1. 確認冷凍、冷藏冰箱門已確實緊閉。
     2. 確認地面無水漬、紙屑與污漬（若有需即刻拖抹乾淨）。
     3. 確認公共電燈與非必要電器電源關閉。
