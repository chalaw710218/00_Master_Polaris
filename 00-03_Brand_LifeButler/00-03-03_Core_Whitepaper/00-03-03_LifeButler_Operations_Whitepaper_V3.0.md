## 一、 創辦人宣告與核心理念 (The Vision)

### 1.1 關於創辦人
**陳品碩，阿美族，台東生活者。**
我出生於花蓮瑞穗的阿美族家庭，自小在台北成長。成長過程中，我既走過嚴格的校園管教，也在社會基層工作中體會勞動者的真實生活。後來回到台東，人生再次轉向——我開始在這片土地上生活、成家，並持續用自己的方式把日子走穩。從跨國巡演到工地勞動，從飯店工程到社區管家，這些經歷讓我深知基層的真實樣貌，也形塑了我做事的框架：嚴謹、務實、果決、體貼。

### 1.2 四大核心理念
我們不只是一家物流公司，我們是一套偏鄉生活基礎建設：
1. **好安居**：讓居民能在自己熟悉的社區中安心生活、幸福老去。不因醫療、採買而被迫離鄉。
2. **好營生**：創造不分身分與背景、人人皆可參與的在地工作機會。讓青年不必離鄉，二度就業者重新站穩。
3. **同質等價**：縮減城市與偏鄉在服務可近性與生活成本上的差距，實現城鄉服務平權。
4. **與自然共升**：在建構生活服務的同時，將節能減碳與資源循環（優化路線、在地供應、包材減量）納入設計核心。

## 二、 結構性市場痛點 (The Problem)

我看見的是一個在台東被放大的結構性困境：
1. **雙平台高抽成**：平台高抽成把價值抽走，留下的是「三輸」：消費者買貴、店家沒利潤、外送員被壓榨。
2. **距離與資訊落差**：台東的店家不是不會經營，而是先天被距離成本與資訊落差拉高了生存門檻。
3. **市場規模小與競爭不足**：偏鄉被迫接受「比較差」變成常態：同價不同質、同費不同等。
4. **低薪造成人口流失**：青年外流不是單一事件，而是會「自我加速」的地方經濟惡性循環。
5. **高齡化加劇與長照破碎**：長照有做，但做得太碎，接不起生活的全貌；臨時與生活型的需求最容易被漏接。

**【根本矛盾】**：在地服務供給不足（成本高、制度碎） vs. 生活需求更迫切（偏鄉、老化），兩者落差越來越大，形成極大的「生活服務缺口」。

## 三、 解決方案與三端樞紐 (The Solution)

我們採用**「三端一體」**作為發展主軸，補足在地最後一哩路：

1. **品牌與系統端 ｜「生活的一部份，就醬點！」**
   - 作為單一入口與中樞（導流、下單、結算）。讓需求與供給「看得見、叫得到」。
2. **實體據點端 ｜「家宅 (Community Hub)」**
   - 不只是倉庫，而是社區服務中心。以團購為起點，將分散訂單集中，降低配送成本，並延伸在地服務（代倒垃圾、跑腿、洗衣）。
3. **物流交付端 ｜「寶桑物流生活商行 (承攬車隊)」**
   - 第一線基層服務提供者。維持運能彈性與成本效率，完成最後一哩路的實體交付。

## 四、 三階段事業擴張藍圖 (The Roadmap)

本計畫採三階段推進，確保擴張建立在可被驗證的營運能力之上：

### Stage 1：基礎建構期 (穩住現有運作)
- **目標**：先把「能服務」做穩。建立平台入口與車隊交付能力。
- **現況**：已具備 LINE 導流、7 間合作店家與 8 名外送員。完成餐飲代送、團體代訂與代倒垃圾的 MVP 驗證。

### Stage 2：資源整合期 (據點化與生活服務深化)
- **目標**：把「能擴張」做成系統化與網絡化。
- **行動**：
  - **系統整合**：建構營運中台，數據互通。
  - **物流升級**：發展點對點集運配送，合併路徑。
  - **人力整合**：形成「專職＋兼職」混合型運力網絡。
  - **服務擴充**：導入 `00-06 循環經濟` (二手資材流轉) 與跑腿代買，提高客單與黏著度。

### Stage 3：未來願景期 (公司化與幹線化)
- **定位**：寶桑物流生活科技股份有限公司。
- **三大願景模組**：
  1. **超級 APP**：把分散服務整合成單一入口（整合 `00-07 TWQR` 微型金流）。
  2. **火車集運**：形成「幹線（火車）＋末端（機車）」的兩段式物流，跨鄉鎮擴張。
  3. **勞動合作社**：建立穩定、防剝削的地方運力與站點自治單元。

## 五、 SWOT 分析與風險控管 (Risk Management)

| 構面 | 內容與策略 |
| :--- | :--- |
| **優勢 (Strengths)** | **LINE 低門檻導流**、**家宅需求聚合器**、**承攬車隊高彈性**、多場景生活物流（降低單一品類風險）、價值主張（同質等價＋好營生）。 |
| **弱勢 (Weaknesses)** | 初期訂單密度不足、多角色營運複雜。**因應：**透過 SOP 標準包、查核點與 KPI 報表制度化管理。 |
| **機會 (Opportunities)**| 偏鄉服務缺口明確（我們的主場）、家宅站點可快速複製擴張、生活物流場景多元能分散餐飲淡旺季波動。 |
| **威脅 (Threats)** | 雙平台補貼價格戰、準直接競品（如台灣大車隊快遞）、宅配通替代壓力、勞動政策變動。**因應：**以在地社區聚合建立防禦，跨縣市物流採合作分工，並落實制度先行（保險/合約）降險。 |

## 六、 附錄：AI 戰略武器庫 (The Arsenal)

為了確保我們在商業拓展與上游談判中佔據絕對優勢，我們已建立專屬的 AI 營運中台工具：

2. **`利刃商品七步分析 (sharp-groupbuy-analyzer)`**：全自動化的管家選品引擎。輸入商品圖文後，自動完成：市調 $\rightarrow$ 成本逆推 $\rightarrow$ 定價策略 $\rightarrow$ 產出符合「喵編」人設與 SEO 規範的精準行銷圖文。
