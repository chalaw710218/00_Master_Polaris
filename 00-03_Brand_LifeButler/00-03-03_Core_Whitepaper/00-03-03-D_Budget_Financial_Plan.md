# 附件 D：財務預算編制與損益平衡試算表 (3個月試辦期旗艦版)

本附件詳細編列「生活管家」試辦期（前 3 個月）之資本支出（CAPEX）、營運費用（OPEX）、主要商品核心大宗採購代墊週轉池（Working Capital），以及各業務線之單元經濟（Unit Economics）與損益平衡點（Break-Even Point, BEP）測算。

---

## 一、 預算編制基本架構與邊界條件

依據創辦人決策與真實供應鏈規格，本案採**「極致精益（Lean）人事＋重砲級供應鏈大宗採購代墊」**模式：
1. **試辦期戰略目標**：**以 3 個月為死線（Dead-Line）**，驗證「三端一體」之造血與互助閉環，實現單月收支平衡。
2. **核心人力編制**：全職專職管理人員僅創辦人品碩 1 名，**固定薪資 NT$ 30,000 / 月**；其餘外送車隊、清潔人員與包裝作業採「論件計酬／分潤制」，不墊高剛性人事成本。
3. **場域與冷鏈硬體基礎**：
   * **家宅現址**：由合作夥伴協助共用場域（免除沉重獨立租金壓力）。
   * **家宅內部冷鏈資產**：臥式 6 呎上掀式冷凍冰箱、直立式展示冷藏櫃（已由呂叔天使投資 NT$ 60,000 實物到位，作為家宅分裝與履約交貨樞紐）。
   * **大宗大冷凍櫃（外租大庫存倉）**：為容納 1.3 噸大宗生鮮肉品批發（雞胸 540kg + 雞腿 540kg + 牛板腱 250kg），採取輕資產「以租代購」模式，**外租大型低溫冷凍庫，租金 NT$ 4,500 / 月**，免除數十萬巨額購置資本支出。

## 二、 核心血脈：主要商品（生鮮肉品大宗批發）代墊採購資金池

依據創辦人實戰供應鏈行情，三大主要商品（核心主力款／零差價引流款）單批採購規模如下：

| 主要商品品項 | 採購單價 (NT$/kg) | 單批進貨規格/數量 | 單批總採購金額 (NT$) | 備註與市場定位 |
| :--- | :--- | :--- | :--- | :--- |
| **生鮮雞胸肉** | 140 元 / kg | 540 公斤 (約 30 箱) | **75,600 元** | 業務用核心品項、舒肥加工母原料、店家剛需 |
| **T8 帶骨雞腿** | 140 元 / kg | 540 公斤 (約 30 箱) | **75,600 元** | 便當店、炸物店、熱炒店家常態高頻大宗原料 |
| **牛板腱** | 400 元 / kg | 250 公斤 (約 10~12 箱) | **100,000 元** | 高單價牛肉麵店、排餐、家庭高階牛肉剛需 |
| **三大主力肉品單批合計** | — | **總重 1,330 公斤** | **NT$ 251,200** | **單批全品項滿載大盤採購金額** |

### 💡 資金週轉與代墊策略規劃：
* **滿載單批極限週轉池**：**約 NT$ 250,000**（若三大主力肉品同一週全數下單進貨）。
* **實戰彈性輪動週轉池（建議基準）**：
  * **初期輪動模型**：每週主力輪動 1~2 項（例如本週雞胸肉 540kg + T8雞腿 540kg 約 15 萬元；或單批牛板腱約 10 萬元）。
  * 配合好市多代購與其他生鮮代墊，**常態流動資金水庫建議配置 NT$ 150,000 ~ 250,000**。
* **回款與週轉天數（負營運資金原則）**：
  * 週一至週三中午彙整店家與社區預購訂單 $\rightarrow$ 週三向大盤下單代墊款項 $\rightarrow$ 週四到貨驗收現結交付店家與消費者。
  * **落實「現收現付、零賒欠」鐵律**，資金週轉週期壓縮在 **3~5 天內全數回籠**，本金不消耗，持續高速滾動。

### 💰 啟動資金總體結構彙總

$$\begin{aligned}
\text{消耗性開辦與營運預算} &= \text{CAPEX } (30,000) + \text{OPEX 3個月 } (150,000) = \mathbf{NT\$\ 180,000} \\
\text{大宗肉品與貨品流動週轉池} &= \mathbf{NT\$\ 250,000} \quad \text{（主要商品核心代墊流動款）} \\
\hline
\mathbf{總資金準備水位 (Total Capital)} &= \mathbf{NT\$\ 430,000 \approx 43 \text{ 萬元}}
\end{aligned}$$

> 💡 **財務深度洞察**：
> 1. **消耗性成本精準（18 萬元）**：前 3 個月包含創辦人薪資（9萬）、5人外送裝備與全額年繳團險（2.7萬）、大冷凍庫3個月租金（1.35萬）、水電公基金等，合計剛好 18 萬元。
> 2. **資產型週轉金（25 萬元）**：作為握有 1.3 噸肉品大盤定價權的週轉池。每週四五現金回籠，持續高速自轉。

## 四、 單元經濟（Unit Economics）與造血路徑

本系統透過「主要商品大宗引流」綁定店家與家庭，並靠其他高毛利服務實現獲利堆疊：

```
                              【單月收入堆疊模型】
   ┌──────────────────────────────────────────────────────────────┐
   │ 1. 便當快閃與代送 (40~50個/日 × 20元利潤 × 22天) = NT$ 17,600~22,000│
   │ 2. 外圈包月垃圾清運 (999/1999方案，約 10~15 戶) = NT$ 15,000~20,000 │
   │ 3. 主力商品細分裝與好市多代購 (每週 80~100 包/單)= NT$ 8,000~12,000 │
   │ 4. 跑腿代買與外送抽成 (里程+8%，每日 8~12 單)    = NT$ 6,000~10,000   │
   │ 5. 雙人居家清潔派單 (每週 2~3 場，提撥 25% 管理)  = NT$ 4,000~6,000    │
   └──────────────────────────────────────────────────────────────┘
```

## 五、 損益平衡點（BEP）測算：第三個月目標

以每月固定剛性支出 **NT$ 42,000**（含創辦人 3 萬元薪資、外租大冷凍庫 4,500 元、水電耗材等）為損益平衡底線：

| 業務模組 | 達成 BEP 的月業務量目標 | 預估貢獻毛利 (NT$) |
| :--- | :--- | :--- |
| **① 「一起叫便當」快閃** | 每日快閃銷售 **35 個便當**（單個毛利 20 元 × 22 工作天） | **15,400** |
| **② 外圈代倒垃圾包月** | 累計簽約 **10 戶**（5戶 999 輕量方案 + 5戶 1999 旗艦方案） | **14,990** |
| **③ 好市多代購與分裝包** | 每週常態交付 **75 包**（分裝工本費與代購費，月計 300 包 × 25 元） | **7,500** |
| **④ 外送與跑腿代買** | 每日平穩出勤 **7 單**（每單綜合毛利 25 元 × 30 天） | **5,250** |
| **合計每月造血總收益** | **各模組達標之綜合毛利** | **NT$ 43,140** |

$$\text{月淨收益} = \text{毛利 } (43,140) - \text{固定營運成本 } (42,000) = \mathbf{+NT\$\ 1,140} \quad \text{(順利跨越損益平衡點！)}$$

## 六、 三個月里程碑與執行死線 (3-Month Action Roadmap)

* **第 1 個月（磨合、冷啟動與主力肉品首波測試）**：
  * 完成真空包裝機、外送箱到位；家宅動線整理完成。
  * 啟動雞胸肉或 T8 帶骨雞腿首批大宗預購（鎖定合作便當店與熱炒店）。
  * 啟動「一起叫便當」第一階段（鎖定 1~2 家店家），快閃衝刺人流，達到每日 20 個。
  * 招募首批 3~5 戶外圈包月倒垃圾住戶。
  * 目標毛利：NT$ 15,000（虧損由開辦週轉金吸收）。
* **第 2 個月（放大肉品批發、好市多上線與自取常態化）**：
  * 主力肉品常態化週轉（雞胸、雞腿、牛板腱交替採購），週轉金活化率達 80%。
  * 開啟好市多生鮮冷凍代購拆分，上架 5 款爆款商品。
  * 便當快閃穩定在 35 個/日；推進週六日家宅自取服務。
  * 外圈包月倒垃圾拓展至 8 戶。
  * 目標毛利：NT$ 28,000（接近收支平衡）。
* **第 3 個月（全速造血與正式打平）**：
  * 達成全模組 BEP 目標（便當 35+ 個/日、垃圾包月 10+ 戶、常態代購每週 60 包、大宗肉品穩定週轉）。
  * 單月毛利突破 **NT$ 40,000**，正式覆蓋創辦人 3 萬元薪資與場域水電耗材！
  * 產出首季營運成績單，作為後續申請政府專案、擴展新據點之最強實體依據。
