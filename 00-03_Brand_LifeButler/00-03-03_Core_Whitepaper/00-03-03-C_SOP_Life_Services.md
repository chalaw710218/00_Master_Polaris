# 附件 C：微型生活服務運作手冊（300 公尺雙圈劃分）

本附件詳細定義「生活管家」之核心生活服務清單、以「家宅」為圓心之 300 公尺雙圈空間劃分原則、服務項目細則、接單派工與收費定價規範。

---

## 一、 空間劃分哲學：300 公尺「雙圈模型」

依據物理距離、移動工具與服務性質，劃分為「內圈社區互助」與「外圈商業營利」雙軌：

```
                      ┌───────────────────────────────────────┐
                      │    外圈：300 公尺以上（商業營利圈）     │
                      │    • 物流工具：機車車隊 / 寶桑物流     │
                      │    • 服務對象：一般消費者、在地店家    │
                      │    • 計價原則：市場行情 / 現金收費    │
                      │                                       │
                      │    ┌─────────────────────────────┐    │
                      │    │  內圈：300 公尺內（社區互助圈） │    │
                      │    │  • 物流工具：徒步 / 推車    │    │
                      │    │  • 服務對象：長者、新住民   │    │
                      │    │  • 計價原則：數位點數/時間銀行│    │
                      │    │                             │    │
                      │    │        [ 家宅 Hub ]         │    │
                      │    └─────────────────────────────┘    │
                      └───────────────────────────────────────┘
```

| 維度 | 【內圈】300 公尺內（社區互助圈） | 【外圈】300 公尺以上（商業營利圈） |
| :--- | :--- | :--- |
| **核心定位** | 鄰里陪伴、老弱關懷、情感凝聚之互助基地 | 高效率便民、時間變現、實質造血創收 |
| **交付工具** | 徒步、手推車、自行車（零碳綠色履約） | 機車外送、商用物流車輛 |
| **主要對象** | 在地長者、行動不便者、新住民、據點鄰居 | 雙薪家庭、外送愛好者、非特約店家、跨區住戶 |
| **支付方式** | **全包式會員制（規劃中）／LINE 點數時間銀行** | **依案報價（5D時間矩陣）／包月商業合約／現金** |
| **回饋機制** | 志工獲取服務時數與兌換點數；公基金定額補貼 | 扣除運能成本後，固定提撥回饋家宅公基金 |

---

## 二、 雙圈各項微型服務規範與 SOP

依據目前實務現況與規劃，各項服務運作模式如下：

### 1. 代倒垃圾【執行中】
* **【內圈互助】**：
  * **服務型態**：規劃走向「**包月會員制**」，以固定會費包攬全部生活基礎互助服務（定價研擬中）。
  * **當前互助模式**：定時關懷長輩，約定傍晚垃圾車抵達前步行到府收取。家戶垃圾需妥善包紮防漏，落實資源回收分類，單趟以 1 大包或 2 小包為限。
* **【外圈商業】（商業服務模型）**：
  * **輕量方案**：**999 元 / 月**（每週服務 2 次，適合垃圾量較少之小家庭）。
  * **旗艦方案**：**1,999 元 / 月**（每週服務 5 次，適合高頻垃圾產出之家庭或微型工作室）。
  * **規範**：定點定時清運，透天置於門口、大樓置於約定處。

---

### 2. 包裹代收與安全暫存【尚未規劃】
* **現況標註**：目前列入中長期儲備項目，暫不開放對外營運。後續待家宅空間動線規劃與防盜倉儲條款完備後另行發布。

---

### 3. 冰箱借冰（冷鏈共享服務）【規劃中】
* **創新理念**：善用家宅一樓專業冷凍、冷藏商業冰箱資源，解決偏鄉住戶團購退冰、家庭冰箱空間不足痛點。
* **統一計費規範（內圈與外圈統一標準）**：
  * **當天借冰**：**完全免費（0 元）**。
  * **次日起算**：每件收取 **20 元 / 天**（單件規格不超過 30 × 30 × 30 cm）。
* **安全條款**：
  * 必須妥善密封貼附「借冰標籤」（姓名、電話、存入時間、預計取出日）。
  * 嚴禁存放未密封生肉血水、易腐敗變質物或具強烈氣味之物品。

---

### 4. 代跑腿、代訂餐與代採購【部分執行中】
原則上均採**「集單履約」**，依內外圈實行差異化模式：

#### (1) 「一起叫便當」專案（兩階段佈局）
* **【第一階段：行銷曝光與人流引爆】**
  * **目標**：品牌行銷、社區曝光與微型造血。
  * **運作模式**：週一至週五中午，每天精選合作店家之「單一招牌品項」。
  * **SOP 節奏**：前一天向店家預定數量 $\rightarrow$ 當天 10:30 前完成取餐 $\rightarrow$ 換上管家專屬高質感包裝（賦予情緒價值） $\rightarrow$ 派車拉至高人流聚集區（如醫院、火車站等）定點快閃販售。
  * **利潤機制**：以協助店家行銷宣傳為基礎，**每個便當獲取 20 元利潤**。
  * **待確認合作名單**：
    1. 東食力盒子（正氣店）
    2. 東食力盒子（更生店）
    3. 職人食堂
    4. 職人雙響丼（鐵花店）
    5. 馬蘭魷魚羹麵
    6. 都蘭錦鸞越式料理
* **【第二階段：社區深耕與定點自取】**
  * **目標**：深化社區高頻黏著度與自取服務。
  * **運作模式**：週六、日提供便當自取服務。前一天確認店家單一品項，當天 10:30 取餐後送至「家宅」供社區民眾定點自取。
  * **外送補貼**：若社區民眾需要專人送到府，**每單加收 19 元運費**。

#### (2) 代採購【執行中】
* **【內圈鄰里】**：採集日常雜貨需求（順路採買），提供約定定點時間之「家宅自取服務」。
* **【外圈跑腿】**：
  * **計價與報價機制**：依照任務類型、急迫性與困難度，全面導入「**北極星 5D 價值精算（估價）時間矩陣引擎**」進行客製化報價並指派車隊執行。
  * **代墊款階梯費率（風控條款）**：
    * 跑腿代買原則上以 **單筆訂單金額 2,000 元以內** 為主要服務範圍。
    * **階梯加收運費機制**：若代買總金額超過 2,000 元，為反映司機代墊之現金流壓力與風險成本，**每增加 2,000 元為一個累進單位，額外加收一個單位的運費／服務費**（例如：代買總額 2,001～4,000 元加收 1 單位運費；4,001～6,000 元加收 2 單位運費，依此類推）。大額採買亦可由消費者先行完成預付款轉帳以降低出勤風險。

---

### 5. 代領藥（慢箋健康互助）【規劃中】
* **服務精神**：守護社區長輩連續處方箋領藥安全，避免獨居長者因行動不便中斷用藥。
* **標準作業規範 (SOP)**：
  1. **委託授權**：必須取得家屬或本人簽署之「代領委託書」及健保卡、慢箋正本。
  2. **定點取配**：由專職管家/合格志工至特約合作藥局或診所領取。
  3. **藥師把關**：由執業藥師封裝並加蓋確認章，志工不得私自拆封更動藥品內容。
  4. **送達確認**：親交本人或家屬，並進行基本精神狀態回報與用藥關懷。
* **計費原則**：
  * **內圈長輩**：列為公益關懷項目，免收服務費（或由家宅公基金直接補貼志工出勤津貼）。
  * **外圈住戶**：依專案代辦服務，全面導入「**5D 時間矩陣**」進行報價；對於**山線、海線、南迴線**，規劃提供每週固定「集單定時履約送到府」之長途健康守護服務。

---

## 三、 服務防呆與安全免責守則
1. **貴重物品不代收**：包裹申報價值超過 3,000 元、現金、金飾、證件等貴重品項一律謝絕代收。
2. **食品冷鏈黃金 2 小時**：到府交付若住戶未應門，生鮮物品將退回冷藏庫，通知次日重派，確保無食物中毒風險。
3. **無接觸簽收留痕**：代倒垃圾與代跑腿交付過程一律拍照存證於專屬 LINE 記錄，保護長輩與志工雙方權益。
