# 🐱 00-03-06 Threads 喵編戰報與社群主機 (Threads Meow Hub)

> **定位**：生活管家面向全台灣年輕受眾、煮婦與都會上班族的「高互動純文字前哨站」。  
> **發話主角**：**喵編 (Meow)** —— 生活管家台前看板娘兼社畜打工貓。  
> **戰略定位**：以高情商、懂吃、會做菜、愛吐槽老闆（闆仔）的親民形象，吸引自然演算法互動，建立極致信任，將公域流量無痕導流回生活管家 LINE OA 與門市據點。

## 🎯 核心運作三鐵律

1. **雙簧人設分工（喵編前台，闆仔後台）**：
   * 發文與回覆 100% 由「喵編」具名進行。
   * 闆仔（創辦人品碩）作為喵編貼文裡的靈魂男主角（「闆仔又去送外送了」、「闆仔看報價臉超臭」），塑造實幹、誠實但木訥的老闆形象。
2. **零硬廣，純社交，極限互動**：
   * 內文嚴禁放促銷傳單或購買連結。
   * 每篇貼文的終點永遠是「引發共鳴、拋出問題、誘發網友在留言區回覆」，以榨取 Threads 演算法的對話深度推播。
3. **導流閉環**：
   * 在帳號個人簡介 (Bio) 放置官方微型傳送門（LINE OA 點餐與客服）。
   * 留言區只有在網友主動詢問「哪裡買」、「怎麼訂」時，喵編才以俏皮口吻引導至個人簡介。
