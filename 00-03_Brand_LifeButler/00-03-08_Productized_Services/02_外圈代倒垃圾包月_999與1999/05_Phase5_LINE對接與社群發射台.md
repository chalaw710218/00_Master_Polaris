## 一、一鍵倒垃圾雷達·雲端部署指南 (Zero-Cost 靜態託管)

### 推薦方案 A：GitHub Pages (最推薦，現有生態直通)
1. 將 `05_Trash_Radar_Engine` 目錄內容推送到 GitHub 倉庫的 `gh-pages` 分支或 `/docs` 資料夾。
2. 開啟 GitHub Pages 即可獲得安全 HTTPS 網址：
   `https://[username].github.io/trash-radar/`

- 直接拖曳 `05_Trash_Radar_Engine` 資料夾上傳，30 秒內即可生成全域 CDN 加速之 HTTPS 網址。
