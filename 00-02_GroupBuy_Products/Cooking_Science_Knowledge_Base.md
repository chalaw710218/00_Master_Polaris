## 一、 食材冷水下鍋 vs. 滾水下鍋科學對照表（已核實）

### 1. 冷水下鍋組（Slow Extraction & Gradual Heating）
| 食材種類 | 科學原理與操作關鍵 | 目的與成效 |
| :--- | :--- | :--- |
| **帶骨排骨 / 大骨** | 冷水下鍋，加入薑片、料酒；微滾後撈去浮沫，溫水沖洗。 | 慢速升溫使骨髓與深層肌紅蛋白由內而外滲出凝固，徹底去血水與腥味；滾水會鎖死表面蛋白質導致內部腥味出不來。 |
| **生鮮雞肉 / 雞肉塊** | 冷水下鍋，水微滾冒泡即關小火慢煮或撈出。 | 避免雞皮急遽收縮捲曲破裂，使肉質保持軟嫩多汁，熬湯清澈透亮。 |
| **豬五花 / 蹄膀肉塊** | 冷水下鍋，大塊肉質慢透。 | 厚重肉塊均勻受熱，有效逼出深層殘留血水與腥羶味。 |
| **根莖類（馬鈴薯/地瓜/胡蘿蔔）** | 冷水下鍋加蓋慢煮。 | 澱粉與果膠需隨水溫逐步糊化軟化。滾水煮會導致「外層煮爛成泥、內芯仍生硬夾生」。 |
| **乾貨泡發（木耳/香菇/筍乾）** | 泡發後冷水入鍋微煮。 | 讓脫水細胞緩慢、均勻吸水膨脹，保持厚實脆嫩口感。 |

### 2. 滾水下鍋組（Heat Shock, Enzyme Inactivation & Nutrient Locking）
| 食材種類 | 科學原理與操作關鍵 | 目的與成效 |
| :--- | :--- | :--- |
| **綠色蔬菜 / 豆類** | 大火水滾後下鍋，加入少許鹽與油脂，30-60秒快速撈出泡冰水。 | 85°C-100°C 高溫瞬間鈍化「葉綠素分解酶」，油脂封鎖氧化，鎖住青翠色澤與水溶性維生素 C，避免泛黃。 |
| **鮮蝦 / 蝦蟹甲殼類** | 滾水下鍋，加入蔥薑米酒，蝦身彎曲變紅浮起即刻撈出。 | 蝦青素（蝦紅素）與蛋白質受熱瞬間定型，外殼香氣釋放，肉質緊緻彈牙不流失甘甜。 |
| **魚片 / 嬌嫩海鮮** | 水大滾或微滾（湯霜法），下鍋數秒至 1-2 分鐘即起。 | 魚肉肌纖維短且嬌嫩，冷水慢煮會散碎成渣；熱水快速凝固表面，鎖住魚油鮮甜。 |
| **花椰菜 / 十字花科** | 滾水加鹽，燙 1-2 分鐘。 | 快速去生澀草腥味、殺滅夾縫蟲卵殘留，保持爽脆口感與蘿蔔硫素。 |
| **貝類（蛤蜊/海瓜子）** | 滾水下鍋，開殼一個夾出一個。 | 閉殼肌受熱蛋白變性瞬間鬆脫張口。冷水慢煮會導致貝肉萎縮乾癟、汁水流失。 |

## 二、 「就醬點」現有主力選品之聯動置入話術點

1. **大明毛豆仁 / 茶豆仁**：
   * **科學對照**：對應「滾水加鹽殺青」。
   * **選品說服力**：大明食品外銷廠已在產地採收黃金 4 小時內完成高溫蒸氣極速殺青與急速冷凍，客人買回家「免開火、免顧爐」，流水解凍即享完美的翠綠爽脆與高甜度。

2. **屏東枋寮午仔魚**：
   * **科學對照**：對應「魚類嬌嫩組織熱水快燙（日式料亭湯霜去腥術）」。
   * **選品說服力**：現撈午仔魚油脂極豐，教顧客下鍋煎前用滾水淋魚皮 3 秒洗去殘留黏液黑膜，下鍋乾煎外皮酥如餅乾、魚肉爆汁。

3. **山億國產清雞胸肉 / 肉品**：
   * **科學對照**：對應「冷水慢煮去血沫」與「低溫 68°C 舒肥浸泡原理」。
   * **選品說服力**：大廠代客修清冷鏈分裝，教顧客打破水煮雞胸乾柴迷思，用溫水慢浸煮出鮮甜嫩雞。
