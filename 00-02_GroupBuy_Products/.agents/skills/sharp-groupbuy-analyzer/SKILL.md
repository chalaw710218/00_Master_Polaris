# 利刃商品七步分析 (管家選品版)

## Overview
本技能將「商品行銷企劃」與「供應鏈底價審計」濃縮為全自動的七步驟流程。當使用者提供產品圖片時，Agent 將自動解析圖片文字、調查市場價格與公司背景，**並套用萬用逆推協議找出上游真實利潤**，接著制定定價策略，最後產出嚴格符合「生活的一部分，就醬點！」品牌人設（喵編管家）的 Facebook 貼文、Google SEO 文案與多張行銷宣傳圖。所有的分析報告與素材都將自動匯出至專屬廠商資料夾。

## Quick Start
請使用者提供產品圖片（包含正面與背面營養標示/說明），並輸入以下指令：
「請用『利刃分析』幫我處理這些產品照片。」

## Workflow
Agent 在被呼叫此技能時，必須**嚴格依序**執行以下步驟：

### 0. 歷史發布防重審查 (Archive & Duplication Check) 【最高優先】
- **強制優先檢索**：接收到任何新商品資訊或照片後，第一時間必須讀取 `00-03-05_Brand_Content_Hub/03_Published_Archive.md`。
- **重疊度判定**：
  * 比對是否有「同品牌/同品項商品」先前已經發布過。
  * 比對是否有「相同切入主題/相似痛點面向」近期剛推廣過。
- **防撞中斷機制**：
  * **若發現重複或高度相似**：**必須立即暫停自動化流程，向使用者主動回報**：「在 `03_Published_Archive.md` 中發現該品項（或高度相似主題）已於 [日期] 發布過（貼文ID/主題：[XXX]）。請問本次是要『回購再推/更新檔期活動』，還是要切換不同的內容面向（如改從生活場景、三觀故事或料理變化切入）？」
  * 必須與使用者確認推進策略後，才能接續執行後續分析。

### 1. 照片文字萃取
- 使用 `view_file` 等視覺與讀檔工具仔細讀出照片上的所有重要內容（包含品名、品牌、成分、產地、規格、特色標語與保存方式等）。

### 2. 規格與價格市調
- 使用 `search_web` 工具，針對「品牌＋品名＋規格＋價格」進行網路搜尋。
- 尋找主流電商或官網的零售價及批發價。

### 3. 公司與新聞調查
- 使用 `search_web` 工具，針對「製造商名稱或品牌名＋新聞/評價」進行搜尋。
- 確認公司背景，以及是否有近期的負面食安新聞，以確保管家選品的安全性。
- **[例外處理機制]**：若在執行步驟 2 或 3 時，發現該產品為全新品、無網路資訊或查無確切市價，**必須立即中斷流程，並向使用者提問**：「目前在網路上查無此商品的明確市價資訊。為了制定合理的定價策略，請您提供此商品的『進貨成本』或『預期售價』。」收到使用者回覆後，才能繼續後續步驟。

### 4. 競品與市場分析
- 使用 `search_web` 工具搜尋目標市場（預設為台東，或使用者指定的地區）內，其他類似競品的規格及售價。

### 5. 供應鏈逆推與定價策略 (核心審計)
- **啟動萬用逆推協議**：依據步驟 2 查到的市價或使用者提供的進貨價，評估全球原物料指標、物流與摩擦成本，逆推該產品的「產地出貨價」與「上游廠商毛利」。
- **談判籌碼**：提供一段簡短的「高情商談判話術」，協助使用者未來向上游廠商爭取更低的進貨底價。
- **制定定價**：結合逆推出的極限成本，設計強調「品質越級」的行銷切入點，並制定階梯式定價策略（注意：內部估算可使用團購邏輯，但對外文案禁用團購字眼）。

### 6. 撰寫專屬品牌文案 (The V2.2 Copywriting Engine & 4-Prism Matrix)
請嚴格依照 `00-03-05-01_Copywriting_Codex.md` 最高寫作法典與【生活的一部分，就醬點！】品牌規範撰寫：

🚨 **【四大面向折射輸出鐵律 (The 4-Prism Rule)】**：
在完成價格與成本拆解後，泰勒絲必須依據該商品特質，**同時產出以下「四個面向」的完整文案選項或折射矩陣**，供董事長調度發文：
1. 📐 **【專業知識面向】**：直擊商品製程、成分、規格秘密（例如舒肥溫控、去筋工藝、防泡水肉指南）。
2. 🌱 **【成長歷程面向】**：尋找在地好物、拜訪工廠、堅持品管的真實幕後故事（暴露脆弱與真誠）。
3. 🧭 **【三觀哲學面向】**：堅持不賣劣質低價品、生活不將就、在地平權的生活哲學（純分享、無推銷）。
4. 🔥 **【熱點/選品宣告面向】**：結合當季節令或時事，宣告正式上架（含直式規格報價與固定版尾）。

- **發言者人設**：喵編（帶有小虎牙的灰色虎斑貓），語氣為「私人生活管家」，具備餘裕、專業、真誠溫暖且不卑不亢。
- **受眾心理學**：針對台東公教人員與雙薪家庭，**絕對不強調「便宜、省荷包、CP值」**，而是強調**「品質越級（同等花費換到頂級品質）」**與聰明消費的成就感。
- **SEO 規範**：破題前 18 字必須包含「台東/特定區域＋服務場景」。自然融入長尾關鍵字（如：`台東生活管家服務`、`台東專人代買代送`、`台東在地跑腿急件`），關鍵字周圍避免特殊符號。
- **發文黃金結構**：
  1. 質感生活場景破題。
  2. 提出專屬解決方案。
  3. 品質越級與報價（以直式條列報價，展現俐落專業）。
  4. 服務資訊與 CTA：標明固定時間（門市自取：每週四五六 15:00-18:00 / 專人配送：每週四五六 19:00-21:00），明確引導「👉 點擊加入管家專屬 LINE 系統，直接預約下單：[預留網址]」。
  5. 固定版尾（見下方禁語清單後）。
- **絕對禁語**：禁用「團購」改稱「管家選品」；禁用「幫你省錢/不賺價差/俗擱大碗/透明批發價/便宜/划算」改稱「專屬管家選品/品質升級/為您省去繁瑣」；禁用驚嘆號連發、限時搶購、+1 等廉價話術。
- **固定版尾（必須包含且不可更改）**：
  #生活的一部分就醬點 #管家選品 #質感日常 #在地專屬管家
  【在地服務，安心有保障】
  公司名稱：寶桑物流生活商行
  品牌名稱：生活的一部分，就醬點！
  實體地址：台東市正氣北路166巷90號
  服務區域：台東市區、知本、南王、都蘭、東河

- **網路商城精簡版文案 (必須同時產出)**：
  在產出社群文案後，必須再產出一則專用於網路商城的文案，嚴格套用以下要求與格式：
  1. **字數精簡**：去除冗長的推銷鋪陳，開頭情境描述限制在 2 句話以內，直擊重點。
  2. **排版易讀**：嚴格遵守條列式排版，維持手機閱讀的流暢度。
  3. **固定結尾**：行動呼籲（CTA）必須固定包含「線上下單，可選擇外送服務」字眼。

  【管家選品商城專屬格式模板】

  🔥 [精簡情境標籤（約 10 字）]！[產品最大亮點/口感] 🔥

  [份量或價格亮點]：[具體重量]大滿足，在地批發回饋價只要 $[價格]！

  [特色與用途]：[精簡說明口感與優勢]，[列舉 2-3 種適合的料理方式]。

### 7. 製作宣傳圖 (多圖策略)
- 使用 `generate_image` 工具，產出**至少兩張** `1:1` 比例的宣傳圖，若有需要可產出第三張：
  1. **商品實體照**：將商品放置於乾淨的白鐵桌上，背景為專業廚房。畫面必須包含商品完整的商業包裝（外袋/外盒），並清楚展現內容物。**【絕對要求】：若由 AI 生成包裝，包裝上絕不可出現 AI 亂碼文字（若無法確保文字100%正確，請讓包裝保持無字的純色空白狀態），力求消費者買到的實品與宣傳圖一致，避免消費爭議。**
  2. **情境氛圍照**：基於文案切入點生成的高質感生活情境照（需符合「管家選品」的質感與優雅），需留適當空白以便後續加字。
  3. **【選配】特點資訊素材圖**：AI 需自行判斷是否額外生成一張適合用來做「圖文解說 (Infographic)」的素材底圖。

### 📥 最終輸出與資料夾建置規定 (Final Output Protocol)
完成所有分析與製圖後，Agent 必須：
1. **自動建檔歸類**：若使用者尚未建立該產品的專屬資料夾，Agent 需自動解析當前 `00-02` 資料夾下的流水號，並建立一個全新的廠商資料夾（格式例如：`00-02-05_Vendor_[品牌或商品名]`）。
2. 將所有生成的宣傳圖片複製存入該新建的廠商資料夾中。
3. 將第 5 步（成本逆推與談判話術）、第 6 步（最終管家選品文案）彙整為一份 `.md` 文字報告（例如：`行銷企劃與管家文案.md`），也一併存檔至該專屬資料夾中。

## Common Mistakes
- **違規使用團購字眼**：絕對禁止在文案中出現「團購、CP值、省錢、批發價」等字眼，這會嚴重破壞「管家」的人設。
- **包裝文字產生亂碼**：生成商品包裝實體照時，務必在提示詞中強調「無文字的純色包裝」或「無字樣」。
- **忘記存檔至實體資料夾**：必須幫使用者將文件與圖片歸檔至專案目錄。
