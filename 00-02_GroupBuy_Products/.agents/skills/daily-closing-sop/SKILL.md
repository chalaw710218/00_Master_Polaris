# 極星每日收工閉環標準作業程序 (Daily Closing SOP v2.0 · 智能體五層數據對照版)

## 🎯 技能定位
這是極星宇宙與執行長（雪）的**「每日營運閉環與心智校準中樞」**。
旨在為創辦人（品碩）落實「平常在本地高速創作奔跑，每日收工前統一盤點、數據量化、反思對齊與雲端打包」的最高默契。
透過自動化標準流程，確保事業資產 100% 歸檔、資安零洩漏、個人等級真實成長反饋、**AI 五層工程（Prompt/Context/Harness/Loop/Graph）成熟度數據監控**，並藉由幕僚長深度反問，守護創辦人心智頻寬與戰略方向。

## 🛠️ 執行六部曲標準流程

### 【Step 1：當日戰果盤點與 Git 異動檢視 (Daily Inventory)】
1. 執行 `git status` 與 `git diff`，掃描當日所有新增、修改、刪除之檔案。
2. 提煉出今天推進的重大模組與里程碑（如新資料夾、新白皮書、新技能、文案調整、商戰戰情室建立等）。

### 【Step 2：資安與商業脫敏審查 (Security Gate)】
1. 嚴格檢查所有變更檔案，確保無明文密碼、個人隱私或未授權 API Token。
2. 確認機密商業專案（`00-07_TWQR_Promotion/`、`00-11_Reverse_Engineering_Lab/`）依然列於 `.gitignore` 且未被 Git 追蹤，徹底隔離於雲端公開庫之外。

### 【Step 3：營運日誌歸檔與總索引同步 (Logging & Index Sync)】
1. **寫入 `00-00_System_Operations_Log.md`**：
   * 新增以當日日期為標題的條目（例如 `### [2026-11-19 20:30] ...`）。
   * 條列式精準記錄今天完成的核心決策、架構變動與成果。
2. **校對 `00-00_External_Resource_Index.md`**：
   * 確保今天產出的新檔案、新技能或手冊均已建立 Markdown 超連結跳轉。

### 【Step 4：創始人經驗值與六維屬性結算 (Gamification Settlement · 戴明確定性防呆)】
> ⚠️ **【戴明防呆最高門禁】**：
> **絕對禁止任何 AI 或 Agent 透過心算手動修改 `save_data.json`！**（防止大語言模型討好型數值膨脹病灶）。
> 必須 100% 調用確定性 Python 結算腳本，自動套用階梯阻尼係數與單次 +0.25 熔斷線：

```powershell
python .agents\skills\daily-closing-sop\scripts\gamification_settler.py `
  --epic `
  --int-effort high `
  --imp-effort high `
  --will-effort mid `
  --note "今日主線突破摘要"
```
腳本將自動完成阻尼折算、EXP 發放、自動判定 Level Up、金幣錨定與安全寫檔，並輸出標準戰報。

### 【Step 5：AI 五層工程成熟度遙測與數據對照 (AI 5-Layer Telemetry)】
對照基準文件 [`00-00_AI_Five_Layer_Audit_20261119.md`](file:///c:/Users/lenovo/我的雲端硬碟/00_Master_Polaris/00-00_AI_Five_Layer_Audit_20261119.md)，動態審視今天的工作對五層架構帶來的增量或短板現況：

1. **① Prompt（把要求講清楚）**：基準 80.0%（4/5）
2. **② Context（記得背景、不用重講）**：基準 60.0%（3/5）
3. **③ Harness（能用工具真的做事）**：基準 60.0%（3/5）
4. **④ Loop（自己檢查、修正、再做）**：基準 41.7%（2.5/6）★ 最大短板
5. **⑤ Graph（多個 AI 分工合作）**：基準 66.7%（4/6）
* **全系統總體成熟度**：基準 61.7%
* **收工戰報必須印出五層雷達數據與最大短板警示**，指出今日是否有新突破或待修復問題。

### 【Step 6：每日一鍵打包推送到 GitHub (Daily Commit & Push)】
1. 執行 `git add .`（受 `.gitignore` 保護，安全無虞）。
2. 撰寫清晰優雅的單日總結 Commit 訊息，格式如：
   `chore(daily): 2026-11-19 daily closing - [核心里程碑摘要]`
3. 執行 `git push origin main` 同步至遠端倉庫。
