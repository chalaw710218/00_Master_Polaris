## 🛠️ 實戰第一部分：Meta 官方通行證【五步按圖索驥】

### 📌 第 1 步：進入 Meta 開發者後台
1. 打開瀏覽器，前往：[developers.facebook.com](https://developers.facebook.com/)
2. 登入自己的 Facebook 帳號，點擊右上角 **【建立應用程式 (Create App)】**。
3. **【關鍵避坑點】**：用途務必選擇 **「其他 (Other)」 ➡️ 「企業商家 (Business)」**！
4. 為應用程式取個好記的名字（例如：`佩真早餐發射台`），點擊建立。

### 📌 第 2 步：打開「圖形 API 測試工具」
1. 點擊頂部選單的 **【工具 (Tools)】** ➡️ **【圖形 API 測試工具 (Graph API Explorer)】**。
2. 確認右上角：
   * **Meta 應用程式**：選取剛才建立的 App。
   * **用戶或粉絲專頁**：先維持預設的 `User Token`。

### 📌 第 3 步：加入兩大發文必備權限
1. 在右側面板的 **Permissions (權限)** 下拉選單中，搜尋並點擊加入以下兩項：
   * ✅ **`pages_manage_posts`**（允許 AI 替粉專發布貼文）
   * ✅ **`pages_read_engagement`**（允許 AI 讀取互動與留言）
2. 點擊藍色按鈕 **【Generate Access Token (產生存取權杖)】**。
3. **【授權彈窗重點】**：在彈出的 Facebook 授權畫面中，**務必勾選您要發文的「粉絲專頁」**，並一路點選「繼續/完成」。

### 📌 第 4 步：致命關鍵！切換為「Page Token」
> ⚠️ **新手 90% 卡關在此！個人 Token 是不能替粉專發文的！**

1. 點開 **【User or Page (用戶或粉絲專頁)】** 的下拉選單。
2. 這時選單裡會出現您的 **「粉絲專頁名稱」**，請直接點選它！
3. 上方的 Access Token 欄位會瞬間刷新成一串全新字串。
4. **這串代碼，才是真正能發文的「Page Token」！**

### 📌 第 5 步：一鍵升級為「60 天無敵長效金鑰」
1. 點擊 Access Token 欄位旁邊的 **藍色圓形 `ⓘ` 圖示**。
2. 在彈出的視窗中，點擊 **【在存取權杖工具中開啟】**。
3. 頁面滑到最下方，點擊藍色按鈕 **【Extend Access Token (延長存取權杖)】**。
4. 有效期限瞬間升級為 **60 天（約 5,184,000 秒）**！
5. 複製這串 60 天長效金鑰，準備貼入本機電腦保險箱。

## 💻 實戰第二部分：電腦發射台三步配置

請在您的電腦桌面上建立一個資料夾 `my_launcher/`，並放入以下檔案：

### 📁 資料夾結構一覽
```text
my_launcher/
├── .secrets.env            <-- 您的密碼保險箱（填入金鑰與粉專ID）
├── photo.jpg               <-- 您上週產出的故事海報或真實照片
├── draft.txt               <-- 您要發布的文字文案
└── launch_my_post.py       <-- 全自動發射腳本
```

### 🔑 檔案 1：`.secrets.env`（密碼保險箱）
請用記事本打開 `.secrets.env`，填入您的專屬資訊：
```env
FB_PAGE_ID=你的粉專數字ID
FB_PAGE_ACCESS_TOKEN=EAA...你的60天長效金鑰
```
*(如何查粉專數字ID：打開您的 Facebook 粉專首頁 ➡️ 關於 ➡️ 粉絲專頁透明度 ➡️ 即可複製粉專編號)*

### 📝 檔案 2：`draft.txt`（文案草稿）
用記事本打開 `draft.txt`，寫入您想說的話：
```text
【用手作的溫度，開啟台東的美好早晨】

很多人問我們：「為什麼每天清晨四點就要起來備料？」
因為我們相信，一道熱騰騰的現烤吐司與手作蛋餅，不只是早餐，更是一份在地的溫暖陪伴。

今天，把時間買回來，把心意留給每位走進店裡的朋友。
```

1. 在筆電上打開 **Antigravity**。

## 🚑 常見報錯與急救速查表

| 錯誤代碼 / 現象 | 發生根因 | 一秒解決方案 |
| :--- | :--- | :--- |
| **`(#200) Insufficient permission`** | 誤拿個人 User Token 發文 | 回到後台下拉選單，切換為「粉專名稱」的 Page Token！ |
| **`Error: File photo.jpg not found`** | 圖片檔名不對或放在錯的資料夾 | 確認照片檔名為 `photo.jpg` 且放在同一資料夾內。 |
| **`190: Error validating access token`** | Token 已過期或複製時漏掉字元 | 重新在後台延長 Token，整串完整複製進 `.secrets.env`。 |
| **`UnicodeEncodeError` 中文亂碼** | Windows 終端機預設編碼問題 | 腳本開頭已加入 `utf-8` 防呆自動修復，或在終端機輸入 `chcp 65001`。 |
