# 🎓 第 2 講：Antigravity 操作與 Meta 自動發文串接 (11/04)

> **時間**：2026-11-04 (三) 14:00 - 16:00  
> **核心目標**：徹底告別手工複製貼上，打造 24/7 自動發布社群的「全自動數位印鈔機」。

---

## 🧭 課程四大模組

### 1. Google Antigravity 核心架構解密 (35 mins)
* **三大形態速覽**：IDE 桌面端、CLI 終端機（agy）、PWA 手機遠端遙控面板。
* **工作區與技能體系 (Skills)**：Antigravity 是如何調用本機 Python 腳本與 API 的？
* **常用快捷鍵與 `/` 常用斜線指令教學**。

### 2. Meta API 密鑰獲取與資安解耦 (25 mins)
* **Facebook Graph API 申請與權限設定**：Page Access Token、永遠有效的令牌處理。
* **Threads 官方 API 串接**：長效授權與防降權機制。
* **資安第一課**：敏感金鑰如何存放在 `.secrets.env`，並確保 100% 寫入 `.gitignore` 永不洩漏。

### 3. 全自動發布與排程流水線實作 (35 mins)
* **現場跑代碼**：展示 `fb_publisher.py` 如何在 3 秒內抓取本地資料夾文案與圖片發布至 FB。
* **留言防降權機制**：主文發布後秒級在第一則留言留下 LINE 導流連結。
* **預約排程**：學會設定未來 75 天內的定時自動排程發布。

### 4. 實機串接除錯與 Q&A (25 mins)
* 學員現場發出第一篇由 Antigravity 驅動的 Meta 官方貼文！
