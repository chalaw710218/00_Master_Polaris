## 🧭 上半場：核心觀念與操作精講 (14:00 - 15:00 · 60 mins)

### 📌 第一節：Google Antigravity 核心環境解密 (25 mins)
* **三大形態速覽**：IDE 桌面端、CLI 終端機（agy）、PWA 手機遠端遙控面板。
* **工作區與技能體系 (Skills)**：Antigravity 是如何調用本機 Python 腳本與 API 的？
* **常用快捷鍵與 `/` 常用斜線指令教學**。

### 📌 第二節：Meta API 串接與自動排程流水線 (35 mins)
* **Facebook Graph API 申請與權限設定**：Page Access Token、長效令牌處理。
* **Threads 官方 API 串接**：長效授權與防降權機制。
* **資安第一課**：敏感金鑰如何存放在 `.secrets.env`，並確保 100% 寫入 `.gitignore` 永不洩漏。
* **現場跑代碼示範**：展示 `fb_publisher.py` 如何在 3 秒內抓取本地資料夾文案與圖片發布至 FB，並於第一則留言自動防降權導流。

## 🛠️ 下半場：課後動手練習與一對一排錯 (15:00 - 16:00 · 60 mins)

> **目標**：在 60 分鐘內，現場跑通個人的第一支自動發文腳本，真正發布或預約排程成功一篇貼文！

### 🎯 實戰任務 1：本地環境設定與權限驗證 (20 mins)
* 學員在講師協助下打開 Antigravity 工作區，檢查 Python 與必要相依套件環境。
* 建立並配置個人 `.secrets.env` 金鑰檔案，由工程技術團隊防呆驗證 `.gitignore` 狀態。

### 🎯 實戰任務 2：建立商品/貼文素材包 (15 mins)
* 學員準備 1 張實體照片（如商品照、辦公室工作照）與一段文案草稿。
* 放入標準化目錄結構中，由 Antigravity 自動讀取並檢查圖片解析度與文字格式。

### 🎯 實戰任務 3：實機執行自動發文 ＆ 個別指導 (25 mins)
* 現場呼叫發布腳本或發文技能，實機送出第一篇 Facebook 或 Threads 貼文（或設定為未來預約排程）。
* 講師與助教針對個別學員的 API Token 報錯、權限不足問題進行一對一現場診斷修復。
* 成功者獲得現場認證，完成全自動發文閉環！
