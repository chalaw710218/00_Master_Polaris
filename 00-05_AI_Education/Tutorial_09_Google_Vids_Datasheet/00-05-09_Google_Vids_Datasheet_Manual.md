## 🟢 第二章：【A 區】頂部控制台（系統命脈與畫布開關）

這裡是整部影片的「總開關與防呆線」，位置在螢幕最上方由左至右：

| 按鈕圖示 / 名稱 | 實體白話功能 | 物理操作說明 | 戴明防呆警告（按錯怎麼辦？） |
| :--- | :--- | :--- | :--- |
| **📁 影片標題區**<br>*(未命名影片)* | **影片的身分證字號** | 點一下滑鼠左鍵，可以直接打字改名字（例如：`生活管家_午仔魚介紹`）。 | 沒改名字也不會壞，它會預設叫「未命名影片」，但在雲端硬碟裡會很難找。 |
| **↩️ 弧形向左箭頭**<br>*(復原 / Undo)* | **「時光倒流後悔藥」** | **（最重要按鈕！）** 按一下，剛才做錯的事情立刻復原（例如不小心把字刪掉了）。 | 鍵盤快捷鍵是 `Ctrl + Z`。按錯任何東西，狂按這個按鈕就安全了！ |
| **↪️ 弧形向右箭頭**<br>*(重做 / Redo)* | **「前進一步取消後悔」** | 如果剛才按「後悔藥」按過頭了，按這個可以恢復回去。 | 快捷鍵是 `Ctrl + Y`。 |
| **📱 9:16 / 16:9 選單**<br>*(畫布比例切換)* | **「直立手機 vs 橫向電視」** | 點開可選擇 `9:16`（直式短影音 Reels/Shorts）或 `16:9`（橫式 YouTube/電視）。 | 手機看為主的宣傳短片，一律開局就選定 `9:16`，免得做完還要重新排版。 |
| **▶️ 播放按鈕**<br>*(頂部右上角)* | **「全螢幕試播總驗收」** | 點擊會以大螢幕完整預覽整支影片的聲光效果。 | 播放中隨時按鍵盤 `Esc` 就能跳回編輯畫面。 |
| **🔒 共用按鈕**<br>*(藍色外框)* | **「找幫手進來一起改」** | 點開後輸入夥伴的 Gmail 信箱，對方就能在自己的電腦打開同一個畫面幫你改。 | 小心不要把「編輯者」權限給陌生人，一般人給「檢視者」即可。 |

這是中央最大的白色畫布，影片播放時長什麼樣子，這裡一清二楚：

| 操作目標 / 按鈕 | 實體白話功能 | 物理操作說明 | 防呆小撇步 |
| :--- | :--- | :--- | :--- |
| **點擊中央任何文字或圖片** | **「抓取物件」** | 滑鼠點一下，物件外框會出現 **8 個藍色小圓點**。 | 按住邊角的藍色圓點拖拉，可以**等比例放大縮小**，不會把人臉壓扁。 |
| **外框旋轉小圓把手** | **「方向盤歪斜調整」** | 點住外框頂端突出的小把手左右轉動，可以把字體或圖片變斜角。 | 想轉回正水平時，按住鍵盤 `Shift` 再轉，會自動吸附在 0 度水平線。 |

### 1. 🪄【AI 影片】（面板名稱：AI 短片）
* **實體白話**：**「Google Veo 次世代 AI 隨身短片導演」**
* **面板四大分頁開關**：
  * **【建立 (Create)】**：打字描述畫面（例如：*「陽光灑在稻田上，微風輕拂金黃稻穗」*），AI 直接從零算出一整段 1080p 超高清真實短影片。
  * **【編輯 (Edit)】**：針對現有影片片段輸入修改指令（例如：*「把背景換成海邊」*）。
  * **【動畫 (Animate)】**：讓靜態照片動起來（例如：讓靜態的午仔魚照片冒出熱騰騰的白煙蒸氣）。
  * **【增補 (Extend/Infill)】**：當影片長度差 2 秒時，讓 AI 自動往後腦補運算延長。
* **物理操作**：點選「建立」➡️ 輸入白話描述（可點擊小燈泡 💡 參考靈感）➡️ 點擊發送 ⬆️ ➡️ AI 算片完成後自動放入畫布。

* **面板關鍵按鍵**：
  * **場景範圍**：可選【目前場景】（只有這一幕出現）或【所有場景】（全片常駐當旁白主持）。
  * **輸入腳本框**：直接打要它說的字，特別功能：**輸入「`[`」可插入「音訊標記」**（例如控制停頓半秒、呼吸換氣）。
  * **虛擬化身挑選區**：點擊「變更」可挑選不同膚色、年齡、穿著的角色（如截圖中的「芬利 · 輕柔、高音調」）。

  * **熱門主題示範**：
    * `Birthday celebration`（生日慶典、節慶促銷）
    * `Year in review`（年度回顧、大事記幾何拼貼）
    * `Congratulations graduate`（祝賀畢業、通關證書）

### 12. 🎨【圖案】（面板名稱：圖案和線條）
* **實體白話**：**「防吃字色塊底板與指引箭頭箱」**
* **做什麼用**：文字如果放在花俏的照片上會看不清楚，放一個半透明幾何圖案墊在文字後面，文字立刻變得極度清晰！
* **面板四大圖案家族**：
  1. **繪製線條**：直線、折線、曲線、波浪線，用來畫分隔線。
  2. **圖案 $\rightarrow$**：長方形、圓角矩形、圓形、對話雲朵、愛心、笑臉。
  3. **箭頭 $\rightarrow$**：空心箭頭、向左向右向上下、直角轉彎箭頭（專門指著折扣數字或重點商品）。
  4. **圖說 $\rightarrow$**：帶有小尾巴的漫畫對話框、四角星、八角星、爆炸貼紙（寫「特價」最適合用爆炸貼紙！）。

## 🟡 第五章：【D 區】底部膠卷時間軸（影片時間的心臟）

畫面最下方一格一格的方塊，就是「影片分鏡膠卷」。影片就是從第一格順著播放到最後一格：

```text
[ 隱藏時間碼 ]    [ ▶️ 播放 ] [ 00:00.0 / 00:05.0 ]    [ 🔍 ➖---🔘---➕ 放大鏡縮放 ]   [ ➕ 新增場景 ]
+----------------------------------------------------+
| 🔷 場景 1 (0:00.0 - 0:05.0)                         |
|    [白色大畫布]                                     |
|    "這個場景沒有任何物件"                           |
+----------------------------------------------------+
```

| 控制鍵 / 區域 | 實體白話功能 | 物理操作說明 | 戴明防呆建議 |
| :--- | :--- | :--- | :--- |
| **▶️ 三角形播放鍵** | **「試播檢查」** | 點一下開始跑影片，再點一下 ⏸️ 暫停。鍵盤按 **空白鍵 (Space)** 也能開關播放。 | 播放時眼睛盯著畫面，耳朵聽背景音樂會不會太大聲壓過人聲。 |
| **➕ 加號按鈕**<br>*(位於膠卷最右側)* | **「接延長線加一幕」** | 點一下，會在後面新增一張空白場景，讓你繼續排版。 | 不要一部影片塞太多格，一般宣傳片 4~6 格場景（總長約 30~45 秒）效果最好。 |
| **🔍 放大鏡縮放滑桿**<br>*(➖---🔘---➕)* | **「時間軸放大鏡」** | 往 ➕ 拉，膠卷方塊變寬（方便微調半秒鐘的細節）；往 ➖ 拉，整部片全覽。 | 找不到自己在哪個場景時，往 ➖ 拉到底就能一眼看到全貌。 |
| **方塊右側邊緣拖拉** | **「給這幕多活幾秒」** | 滑鼠移到場景方塊右邊緣，游標會變成雙向箭頭 `⬌`，往右拉時間變長，往左推時間縮短。 | 如果這一幕字很多，請拉長到 5 秒以上，給長輩足夠時間讀完。 |
| **拖拉方塊換順序** | **「洗牌調換前後」** | 按住「場景 2」不放，往左拖到「場景 1」前面放開，兩幕立刻調換位置。 | 調換後記得按 ▶️ 從頭播一次，確認邏輯通順。 |

## 🛡️ 第七章：戴明防呆「十秒神救援」自我檢測表（常民安心指引）

萬一在操作時慌了手腳，請默念這三條保命口訣：

1. **❓「字或照片不小心被我刪光了怎麼辦？」**
   👉 **解方**：螢幕左上角的【↩️ 復原】按鈕，按下去立刻救回！快捷鍵按住 `Ctrl` 不放再按 `Z`。
2. **❓「背景音樂太大聲，把說話聲音蓋過去了？」**
   👉 **解方**：點選右側抽屜【🎵 音樂】，把音量拉桿從 `100%` 調降到 `15% ~ 20%`，讓音樂變成輕柔襯底。
3. **❓「怎麼把影片下載下來傳給 LINE 好友？」**
   👉 **解方**：直接點螢幕右上角藍色【匯出 (Export)】，等待完成後點擊「下載」到電腦桌面，就能透過 LINE 或 Facebook 傳給親朋好友了！
