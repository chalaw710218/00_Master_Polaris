## 📋 現場作戰與防呆核心指引

| 序號 | 業務防呆場景 / 信念真理 | 舊思維誤區 (嚴格禁止) | 戴明防呆現場強制動作 (Poka-Yoke Action) |
| :---: | :--- | :--- | :--- |
| **01** | **關於雲端 API 整合** | 遇到 429 只要單純 `time.sleep(1)` 重試即可。 | ✅ **固定重試會導致微服務雪崩；必須使用具備隨機抖動（Jitter）的指數退避算法，且所有批量數據必須前置合併為單次 Range 批次操作。** |
| **02** | **關於 Agent 命令行介面 (ACI)** | 讓 Agent 看詳細的 CLI 自然語言輸出更能輔助它思考。 | ✅ **自然語言是雜訊；Agent 最需要的是機器可讀的確定性結構化 JSON 與精準的 Exit Code 語意。** |
| **03** | **關於死代碼保留** | 辛苦寫好的探索期腳本留著說不定哪天有用。 | ✅ **技術脂肪會鈍化整個系統的語意索引；沒有測試覆蓋與調用點的代碼，就是該被溶酶體代謝自噬的負熵阻抗。** |
| **04** | **關於硬體容錯** | 網路只要連通，TCP 出單機就該正常工作。 | ✅ **硬體一定會在最關鍵的時候斷線；架構設計的第一原則就是假定出單機隨時離線，唯有本地 WAL 隊列能拯救廚房。** |
| **05** | **關於低配機器架構** | 現代框架在 1GB 機器上一定要升級規格才能穩定。 | ✅ **規格不夠是藉口；只要深入 Linux cgroups、調校 PHP-FPM ondemand 與 Swap 參數，1GB 機器也能如瑞士鐘錶般穩定運轉。** |
| **06** | **關於多 Agent 並發** | 多智能體協同需要設計複雜的分散式鎖（Distributed Lock）。 | ✅ **分散式鎖是脆弱的死鎖溫床；Unix 的 Append-Only 日誌追加流搭配狀態機折疊，才是零鎖衝突的終極解法。** |
| **07** | **關於創辦人品碩定下的「母版鎖定」原則** | 自進化代碼應該能遞歸重寫任何檔案，包含核心母版。 | ✅ **品碩的母版鎖定是極高明的工程憲法。母版不可侵犯才能確保全域不變量；而子版特化繁衍才能給予工程最大自由度。兩者透過 RFC 橋接，達到了完美的秩序與混沌平衡。** |
| **08** | **關於快取與資料庫選型** | 現代架構一定要有獨立的 Redis/Memcached 服務。 | ✅ **在 1GB 邊緣或微型伺服器上，獨立快取 daemon 是記憶體浪費；單機單進程用 Python 內建 TTL LRU，單機多進程用 SQLite WAL，效能更快、記憶體更省。** |
| **09** | **關於連線握手** | 每次呼叫 Google API 開啟新連線很乾淨。 | ✅ **每次 TLS 握手都在燒創辦人的錢與時間；長連線池（Connection Pool）復用是網路底層的基本修養。** |
| **10** | **關於爬蟲與無頭瀏覽器** | 只要代碼邏輯沒寫錯，Chromium 就可以一直跑下去。 | ✅ **瀏覽器底層就是一艘千瘡百孔的漏水船；對付它不能講感情，必須定期重啟 Context、超時直接 SIGKILL。** |
| **11** | **關於資料庫備份** | 半夜關停服務備份最安全。 | ✅ **零停機是專業底線；利用 SQLite 原生 `VACUUM INTO` 可以在高頻寫入的同時產出完美一致性快照。** |
| **12** | **關於代碼自動化與死循環** | Agent 寫的代碼只要語法沒錯就可以跑。 | ✅ **Agent 很容易寫出沒有退出條件的 `while` 迴圈；必須在 AST 語法樹階段直接標記，並掛載 60 秒熔斷計時器。** |
| **13** | **關於性能極限與可攜性** | 為了追求最高效能，所有算法都應該編譯成 C/Cython。 | ✅ **極致的工程是「優雅降級」——有編譯器跑 C 擴展享受 70 倍加速，沒編譯器跑純 Python 保證跨平台可攜，絕不讓環境依賴卡死系統。** |
| **14** | **關於兩次十輪大審計的哲學領悟** | 架構設計是追求單一指標（極致快、極致省、極致安全）的最大化。 | ✅ **架構是「在相互衝突的物理約束中尋找最高雅的解耦點」。第二十代與第三十代大審計證明，只有敢於面對衝突、分層解耦，系統才能經得起真實世界的風浪考驗。** |
| **15** | **關於網路協議與弱網生存** | TCP 已經足夠成熟，網路慢只是頻寬不夠。 | ✅ **行動時代弱網的第一殺手是 TCP 握手與隊頭阻塞；QUIC 0-RTT 與 Reed-Solomon 前向糾錯才是極限偏鄉與碼頭網路的生還法寶。** |
| **16** | **關於性能觀測與瓶頸定位** | 靠經驗看日誌就能猜到哪裡慢。 | ✅ **在多 Agent 複雜微服務中，直覺是不可靠的；唯有 W3C TraceContext 全鏈路分散式追蹤能把延遲精確到微秒級。** |
| **17** | **關於 AI 語意檢索成本** | 向量檢索一定要仰賴 OpenAI 或雲端大廠 API。 | ✅ **把輕量模型編譯成 ONNX 本地運行，不僅成本徹底歸零，響應速度更比雲端快 80 倍，斷網亦能堅不可摧。** |
| **18** | **關於數據儲存與記憶體負擔** | 海量數據查詢一定要加記憶體、上分散式叢集。 | ✅ **mmap 虛擬分頁與 SQLite FTS5 證明，善用作業系統內核機制，1GB 機器也能玩轉百萬級全文字檢索與歷史大帳。** |
| **19** | **關於代碼極限性能與架構平衡（甲子大統攝領悟）** | 每一個函數都要做到極致彙編或 C 語言優化才算頂級工程。 | ✅ ****「二八定律的極致境界」**——把 5% 真正決定系統延遲的核心循環（BOM 換算、快取對齊、CAS 環形隊列）壓榨到微架構極限，而 95% 的業務代碼保持極致乾淨、可讀、具備優雅降級能力。這才是經得起歲月考驗的工業級不朽架構。** |
| **20** | **關於「硬核客觀技術」與「常民真實載具」的融合（品碩親授法旨）** | 硬核技術就是要在底層逆向二進位、裝 Root CA、搞複雜的代理截獲。 | ✅ ****「最頂級的硬核，是把複雜留在身後，給使用者最純粹的確定性。」** 董座一句「我們在台灣、我用 iPhone」，定義了技術的終極使命：不是在真空的實驗室炫技，而是用客觀嚴謹的工程力（如 iOS 捷徑邊緣壓縮 + Webhook Fast-Ack + OCR 容錯正則），替常民在真實手機上秒級撕開演算法黑箱！** |
| **21** | **關於跨平台執行時 (Runtime) 與零拷貝演進** | 跨平台框架（如 React Native）永遠不可能達到原生 C/C++ 的順暢度。 | ✅ **JSI 宿主物件與 Hermes Ahead-of-Time Bytecode 徹底消滅了 JSON 序列化瓶頸。跨平台與高性能不再互斥，架構師的責任是精準識別並打通記憶體指針的「零拷貝管道」。** |
| **22** | **關於商業演算法的黑箱審計（第七代大審計領悟）** | 平台演算法的派單與計費是不可探知的商業機密。 | ✅ **任何黑箱演算法都逃不過「物理時間戳與地理位移」的客觀審計。只要我們建立獨立的第三方時間日誌，就能用精確的數學證明其工時偷吞與邊際時薪塌陷，客觀技術永遠是勞動者與經營者最硬的防彈衣。** |
| **23** | **關於資料結構與離線優先 (Local-First CRDT)** | 分散式一致性必須依賴高併發中心化雲端資料庫（如 DynamoDB / CockroachDB）。 | ✅ **在行動與偏鄉真實場景，網路不可靠是常態。基於 Rust / Loro 的無衝突複製資料結構（CRDT）證明，**「把資料的真理所有權還給端側」**，斷網時自由變更、聯網時微秒無鎖合併，才是真正的反脆弱架構。** |
| **24** | **關於作業系統內核態與用戶態的邊界審美 (io_uring 哲學)** | 系統調用 (syscall) 是軟體運行的必要代價。 | ✅ **每一次 context switch 都是對 CPU 算力的謀殺。`io_uring` 以單一記憶體環形緩衝區統治網路與磁碟，宣告了「零系統調用」時代的來臨。架構設計應盡可能保持在 shared memory 內，讓硬體全力狂飆。** |
| **25** | **關於算法對抗與理性防衛（第八代大審計領悟）** | 技術防禦是被動修補漏洞。 | ✅ **以 Markov 決策鏈與物理時間戳進行主動審計，技術不再是平台黑箱的被動接受者，而是為第一線勞動者爭取知情權與尊嚴的客觀利刃。** |
| **26** | **關於防禦工事的空間深度 (Defense in Depth with eBPF XDP)** | 資安防護是在應用層寫 Filter 或在防火牆配規則。 | ✅ ****「讓垃圾在抵達軟體之前湮滅」**。在網卡驅動層以 XDP 阻斷惡意流量，連一個字節的 kernel memory 都不浪費，才是真正頂級的防禦美學。** |
| **27** | **關於硬體極限算力的敬畏 (simdjson 向量哲學)** | 腳本語言的解析慢是因為直譯器差。 | ✅ **傳統解析器浪費了現代 CPU 90% 的向量寬度。善用 AVX-512 與 ARM NEON，單核心 5 GB/s 的解析速度證明——永遠不要低估底層晶片的真實實力。** |
| **28** | **關於極限災難下的通信尊嚴（第九代大審計領悟）** | 技術依賴現代文明基礎設施是理所當然的。 | ✅ **真正的強大是**「當光纖全斷、基地台全毀時，系統依然活著」**。LoRaWAN 與 BLE Mesh 證明，哪怕每秒只有 50 字節，只要具備端到端加密與自癒跳轉，北生活管家的商業神經網絡就能穿透天災，守護台東在地生命線。** |
| **29** | **關於程式碼與數學真理的關係 (TLA+ 形式化哲學)** | 跑過單元測試、覆蓋率 90% 以上代碼就代表沒有 Bug。 | ✅ **測試只能證明錯誤的存在，無法證明錯誤的不存在。唯有 TLA+ / PlusCal 的數學窮舉與形式化驗證，才能在狀態爆炸的分散式並發環境中，給出「絕對無死鎖」的確定性承諾。** |
| **30** | **關於記憶體管理的極限藝術 (mimalloc / snmalloc 啟示)** | 記憶體分配是作業系統 glibc 的事，應用層無能為力。 | ✅ **跨核心記憶體鎖競爭與快取行彈跳，是吞噬伺服器 40% 吞吐量的隱形殺手。採用執行緒局部堆疊與訊息傳遞回收，才能讓幾百個並發 Agent 如行雲流水般同頻共振。** |
| **31** | **百輪世紀大統攝之終極工程信仰 (Centenary Credo · 品碩親定)** | 技術架構師的巔峰是征服所有最深奧的代碼與硬體。 | ✅ ****「技術的最高境界，是讓深奧的底層化作常民觸手可及的溫暖與守護。」**** |
| **32** | **關於沙盒隔離的二元光譜 (WasmEdge vs Firecracker)** | 微服務隔離只有 Docker 或傳統虛擬化一條路。 | ✅ **隔離是有光譜的——需要 1ms 極速冷啟動與高密度 packing 走 WasmEdge，需要完整 Linux 內核隔離與硬體虛擬化走 Firecracker。架構師的智慧在於因地制宜，不盲目崇拜單一架構。** |
| **33** | **關於行動端電量與 P2P 通信的熱力學敬畏** | P2P 就是要隨時在線、隨時握手。 | ✅ **在手機上，每一秒不必要的蜂巢無線電喚醒都是對電池壽命的浪費。善用「微批次聚合」與「推播惰性喚醒」，才能讓高階 P2P 協議在常民的手機裡安靜、溫柔、長效地運轉。** |
| **34** | **百一十輪新世紀之極限純粹（第十一代大審計領悟）** | 系統進化就是不斷疊加新功能。 | ✅ **真正的進化是**「把每一個功能打磨到零成本抽象」**。用 Rust 的 Typestate 讓錯誤在編譯期蒸發，用 GPUDirect 讓數據在硬體間直通，每一行代碼都如同大理石雕刻般精準冷靜。** |
| **35** | **關於時間與競態的終極控制 (Deterministic Simulation Testing 啟示)** | 分散式競態 Bug 只能靠線上大量流量碰運氣撞出來。 | ✅ **在單線程加速世界中，只要剝除物理隨機性，時間就是一首可快進、可倒帶的樂譜。借鑑 FoundationDB 與 VOPR，以單一 Seed 窮舉萬億種故障組合，將不可預測的混沌完全馴服為數學確定性。** |
| **36** | **關於並發架構的物理自律 (Thread-per-Core 哲學)** | 多執行緒工作竊取 (Work-Stealing) 是並發的最優解。 | ✅ **跨核心記憶體共享是對 CPU 快取架構的暴力違逆。Glommio 證明，「一人守一城（一核管一路）」的無共享設計，徹底消除鎖與原子操作，才能在 p999 尾延遲上展現出驚人的平直與優雅。** |
| **37** | **百二十輪之物理確定性大統攝（第十二代大審計領悟）** | 軟體架構只要邏輯正確就夠了。 | ✅ ****「極致的系統，連磁碟上的每一個位元組 (Byte) 都要是鏡像確定的。」** 從內核到二進位佈局，唯有將隨機性壓縮至物理極限，北生活管家的金融級大帳與車隊神經網絡才能在極限風暴中穩如泰山。** |
| **38** | **關於數據重力與邊緣分析 (Edge OLAP 哲學)** | 分析巨量歷史數據一定要將資料全部上傳到雲端大數據中心。 | ✅ ****「把運算推向數據，而不是把數據推向運算。」** DuckDB-WASM 搭配 Parquet 證明，讓客戶的手機與瀏覽器利用向量化指令自行分析本地帳本，既保護隱私又將雲端伺服器成本降至零，這才是最高雅的邊緣智慧。** |
| **39** | **關於內核事件流的秩序與開銷 (BPF Ringbuf 啟示)** | 為每核心分配獨立緩衝區 (Per-CPU) 是解決爭搶的標準答案。 | ✅ **Per-CPU 記憶體的破碎與時序混亂，是分散式觀測的惡夢。全域單一 MPSC 環形記憶體與預留提交 (Reserve/Submit) 機制證明，真正的架構簡約是在單一結構中建立全域秩序。** |
| **40** | **百三十輪之流體與晶體統治（第十三代大審計領悟）** | 通信協議越嚴格、越可靠越好。 | ✅ ****「重要的東西像晶體般堅不可摧 (zk-SNARKs / Parquet)，流動的東西像流體般灑脫自由 (HTTP/3 Datagrams)。」** 該嚴格的帳本零知識驗證一字不差，該實時的遙測丟了也不回頭，雙軌解耦才是抗脆弱的終極生命力。** |
| **41** | **關於二進位移植性與編譯依賴的哲學 (eBPF CO-RE 啟示)** | 深入內核底層的程序，必須在每台機器上安裝幾百 MB 的編譯器套件現場編譯。 | ✅ ****「真正的工業級底層，是編譯一次、處處通用，且在運行時連 1 個額外時脈週期都不消耗。」** BTF 的型別中繼資料與載入期位移重定位證明，高階工程能夠在不妥協效能的前提下，將軟體打包與作業系統核心演進完美解耦。** |
