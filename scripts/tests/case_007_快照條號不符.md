# 測試案例 007：快照條號不符（跨條號比對漏洞阻斷測試）

標記：【應退回】
網址：https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0150002&flno=43
摘句：主管機關對於違反第二十一條、第二十三條至第二十五條規定之事業，得限期令停止、改正其行為或採取必要更正措施，並得處新臺幣五萬元以上二千五百萬元以下罰鍰
說明：網址引用公平交易法第43條，但 snapshots/ 資料夾中故意不提供第43條快照（僅有第21條與第42條）。find_snapshot 必須嚴格比對條號，不得拿第21條或第42條快照充數，找不到精確條號快照時必須判定 FAIL，成功攔截退回。
