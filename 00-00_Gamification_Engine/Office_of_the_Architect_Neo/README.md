## 🧭 一、辦公室最高主權與職權範疇

1. **界面交互終審權**：
   - 任何推向客戶端（LINE、網頁、手機 APP）的界面，未通過尼奧的「零阻力（Zero-Friction）」審查與戴明防呆安燈，嚴禁上線發布。
2. **約瑟夫視覺憲法轉譯權**：
   - 負責將約瑟夫 (CVO) 的 60 項視覺法典 100% 像素級還原為組件代碼（Tailwind CSS / React / Flutter Design Tokens）。
3. **林納斯後端管線客戶端對接權**：
   - 負責與林納斯 (CTO) 的高效後端 API、Devmem TCP 與 Supabase 對接，實踐客戶端離線優先（Offline-First）、樂觀更新與容錯快取。
