## 第 21 輪｜CAMEL（通訊代理人角色扮演與自主合作）
- 網址：https://arxiv.org/abs/2303.17760
- 逐字摘句：To address the challenges of achieving autonomous cooperation, we propose a novel communicative agent framework named role-playing. Our approach involves using inception prompting to guide chat agents toward task completion while maintaining consistency with human intentions.
- 出處：https://arxiv.org/abs/2303.17760
- 核心事實：為應對實現自主合作的挑戰，提出名為角色扮演（role-playing）的通訊代理人框架，使用初始提示（inception prompting）引導聊天代理人完成任務，同時保持與人類意圖的一致性。

## 第 22 輪｜ChatDev（基於多輪對話的虛擬軟體開發社群）
- 網址：https://arxiv.org/abs/2307.07924
- 逐字摘句：In this paper, we introduce ChatDev, a chat-powered software development framework in which specialized agents driven by large language models (LLMs) are guided in what to communicate (via chat chain) and how to communicate (via communicative dehallucination).
- 出處：https://arxiv.org/abs/2307.07924
- 核心事實：ChatDev 是一個由對話驅動的軟體開發框架，由大語言模型驅動的專業代理人透過對話鏈被引導溝通什麼內容，並透過通訊去幻覺被引導如何溝通。

- 逐字摘句：Using this technique, we introduce MemGPT (Memory-GPT), a system that intelligently manages different memory tiers in order to effectively provide extended context within the LLM's limited context window, and utilizes interrupts to manage control flow between itself and the user.
- 出處：https://arxiv.org/abs/2310.08560

## 第 25 輪｜Gorilla（連接龐大 API 與檢索系統集成）
- 網址：https://arxiv.org/abs/2305.15334
- 逐字摘句：When combined with a document retriever, Gorilla demonstrates a strong capability to adapt to test-time document changes, enabling flexible user updates or version changes. It also substantially mitigates the issue of hallucination, commonly encountered when prompting LLMs directly.

- 核心事實：當與文檔檢索器結合時，Gorilla 展現出適應測試時文檔變化的強大能力，並實質上減輕了直接提示大語言模型時常見的幻覺問題。

## 第 26 輪｜Self-Refine（自我反饋與反覆迭代優化）
- 網址：https://arxiv.org/abs/2303.17651
- 逐字摘句：The main idea is to generate an initial output using an LLMs; then, the same LLMs provides feedback for its output and uses it to refine itself, iteratively. Self-Refine does not require any supervised training data, additional training, or reinforcement learning, and instead uses a single LLM as the generator, refiner, and feedback provider.
- 出處：https://arxiv.org/abs/2303.17651
- 核心事實：Self-Refine 不需要任何監督訓練數據、額外訓練或強化學習，而是使用單一大語言模型作為生成器、優化器和反饋提供者，透過同一個模型為自身輸出提供反饋並進行反覆迭代優化。

## 第 27 輪｜Graph of Thoughts（思維圖非線性推理拓撲）
- 網址：https://arxiv.org/abs/2308.09687
- 逐字摘句：The key idea and primary advantage of GoT is the ability to model the information generated by an LLM as an arbitrary graph, where units of information ("LLM thoughts") are vertices, and edges correspond to dependencies between these vertices.
- 出處：https://arxiv.org/abs/2308.09687
- 核心事實：Graph of Thoughts（GoT）將大語言模型生成的信息建模為任意圖，其中信息單元（思維）為頂點，而邊對應於這些頂點之間的依賴關係。

## 第 28 輪｜Plan-and-Solve（規劃再求解零樣本思維鏈增強）
- 網址：https://arxiv.org/abs/2305.04091
- 逐字摘句：To address the missing-step errors, we propose Plan-and-Solve (PS) Prompting. It consists of two components: first, devising a plan to divide the entire task into smaller subtasks, and then carrying out the subtasks according to the plan.
- 出處：https://arxiv.org/abs/2305.04091
- 核心事實：Plan-and-Solve（PS）提示法包含兩個組件：首先制定計劃將整個任務分解為較小的子任務，然後根據該計劃執行這些子任務。

## 第 29 輪｜LATS（語言代理人樹搜尋統一推理行動與規劃）
- 網址：https://arxiv.org/abs/2310.04406
- 逐字摘句：In this paper, we introduce Language Agent Tree Search (LATS) -- the first general framework that synergizes the capabilities of LMs in reasoning, acting, and planning. By leveraging the in-context learning ability of LMs, we integrate Monte Carlo Tree Search into LATS to enable LMs as agents, along with LM-powered value functions and self-reflections for proficient exploration and enhanced decision-making.
- 出處：https://arxiv.org/abs/2310.04406
- 核心事實：Language Agent Tree Search（LATS）將蒙地卡羅樹搜尋（MCTS）整合至 LATS 中以使語言模型作為代理人，並結合由語言模型驅動的價值函數與自我反思，協同語言模型在推理、行動和規劃方面的能力。
