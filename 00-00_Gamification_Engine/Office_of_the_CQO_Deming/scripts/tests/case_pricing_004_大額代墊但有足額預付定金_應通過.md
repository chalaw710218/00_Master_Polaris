# 5D 報價審查案例 004：大額代墊但有足額預付定金

【應通過】

- **業務防區**：防區 A（5D 報價與外送防彈衣）
- **服務項目**：特約農場團購大額生鮮採購
- **顧客知情確認**：是

### 報價與費用明細
| 項目 | 金額 |
| :--- | :--- |
| 勞務服務費 | 500.00 |
| 代採購款 | 5,000.00 |
| 預付定金 | 3,000.00 |
| 基礎成本 | 200.00 |

---
備註：
總採購代墊款 5,000 元雖超過 3,000 元，但顧客已先行預付 3,000 元定金，淨承擔代墊風險為 2,000 元（<= 3,000 元風控上限），勞務服務費 500 元大於基礎成本 200 元，合規應予放行。
